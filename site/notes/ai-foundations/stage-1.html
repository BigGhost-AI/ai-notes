LESSON 01 / 28

一个神经元到底在算什么

我们想看温度和振动，猜设备是否异常。先分清“交给模型的信息”和“模型算出的答案”，再亲手完成一次判断。

从一台设备开始

假设我们测到两项指标：温度指标 0.8，振动指标 0.3。它们已换算到 0–1 的尺度；0.8 不是摄氏温度。现在的问题是：仅根据这两项信息，能否猜出设备是否异常？

模型，在这里是一套把输入信息变成预测答案的计算规则。给它测量信息，它就按规则算出待核对的答案。

神经元是网络中的小计算单元：输入各乘一个数字后相加，再做一次规定的变换。我们先只用一个单元。

先把四种信息放对位置

先看数字从哪里来，再看它叫什么。下表的四类信息，承担不同工作。

名称与具体值从哪里来用来做什么何时改变
输入
温度 0.8、振动 0.3		测量后交给模型的信息作为本次计算的材料换设备或换一次测量时
标签
训练例用 1 表示异常、0 表示正常		人工检修等外部给出的已知结果训练时指导改进；评估时核对预测换已检查记录时
参数
权重 1、2，偏置 −1		模型内部保存的可调数字；本例手工指定决定怎样组合输入手动调节或训练更新时
预测
本例稍后算出“异常”		模型用输入与参数算出作为待核对的答案输入或参数改变后，重新计算时

标签与预测最容易混淆：标签来自外部检查，预测来自模型。模型完全可能预测“异常”，而检修标签是 0；这时就是预测错了。

新设备可能尚无检修标签：可以先预测，稍后再核对。训练则利用已有标签的记录来调整参数。

权重与偏置怎样参与计算

把温度输入简写为 x₁，振动输入简写为 x₂。下标 1、2 只是区分两项信息，不表示谁更重要。

  • 权重：每项输入前的乘数。本例温度乘 1，振动乘 2；它控制该项怎样影响结果。
  • 偏置：乘积相加后，再统一加上的数。本例是 −1，用来调整整体起点。

权重和偏置合称参数。现在用手工参数完成三步，得到一个分数 z：

  1. 温度这一项：0.8×1=0.8。
  2. 振动这一项：0.3×2=0.6。
  3. 相加并加偏置：z=0.8+0.6−1=0.4。

只把振动权重从 2 改成 1，分数就变为 0.8+0.3−1=0.1。测量没变，变化来自内部组合方式。

分数还要变成一个类别

分数 0.4 还不是“异常”这个类别。这里先用一个叫 sigmoid 的函数，把分数变成 0 与 1 之间的输出：0.4 → 0.5987。

这种放在计算单元末尾、对分数再做变换的函数，叫激活函数。先理解它做什么，完整公式可以稍后展开。

接着设置阈值，也就是做类别选择的分界值：

  • 输出 ≥ 0.5：预测异常。
  • 输出 < 0.5：预测正常。

所以本次是：分数 0.4 → 数值输出约 0.5987 → 预测异常。是否真的异常，还要与外部标签核对。

0.5987 来自手工设置的计算，尚未检验是否可靠，不能直接说“设备真实异常的把握就是 59.87%”。

操作之前，先说清准备改什么

下方实验有输入滑块和参数滑块。每次只改一个量，才能看出变化从哪里来。

  • 只改振动输入：换了本次计算的材料，内部参数保持相同。
  • 只改偏置：换了所有设备共用的内部规则，当前测量保持相同。

训练是根据数据调整参数，让预测改善。本讲手动试；第 4 讲说明怎样衡量好坏，第 5–6 讲说明怎样自动调整。

图中的一条边界线，表示什么？

横轴表示温度输入，纵轴表示振动输入。坐标 (0.8,0.3) 表示横向到 0.8、纵向到 0.3；每个点是一条测量记录。

本例 sigmoid 输出达到 0.5 时，分数恰好达到 0。因此 w₁x₁+w₂x₂+b=0 是正常与异常的分界。

  • 只改偏置：至少一个权重不为 0 时，边界平行移动。
  • 改一个权重：边界通常改变方向与位置；负权重表示增大该输入会降低分数。
  • 两个权重都为 0：分数只剩偏置，输出与输入无关，没有一般的直线分界。
展开最小公式与数值关系

完整写法：z=w₁x₁+w₂x₂+b，p=1/(1+e−z)。x 是输入，w 与 b 是参数，z 与 p 是这次算出的数。

分数 zsigmoid 输出 p采用阈值 0.5 的预测
−2约 0.1192正常
00.5000异常
2约 0.8808异常

换一条输入验算：x=(0.2,0.1)，参数仍是 (1,2,−1)。分数 0.2×1+0.1×2−1=−0.6，输出约 0.3543，判正常。

AI、机器学习、深度学习之间是什么关系？

人工智能（AI）研究让机器完成识别、推理、生成等任务，也包括基于规则的路线。

机器学习从数据中改进任务表现；深度学习使用多层神经网络。此处选择神经网络这条路线，先看清最小计算单元。

亲手移动一条判断边界

实时计算 · 输入是假设的设备指标，权重与偏置由手工设置；不进行训练。

先预测再操作：先只把偏置从 −1 改成 −1.5，猜类别是否改变；重置后，只把振动输入改成 0.6，比较两种操作。

输入 (0.8, 0.3)；参数 (1, 2, −1)；z=0.4；p=0.5987；预测异常。

乘积 0.8 与 0.6，加偏置 −1，得到 0.4。

实验解释与可验算的对照
条件分数 z输出 p预测

反例：两个权重都为 0 后，再动输入也不会改变输出，因为算式中已没有输入的贡献。

查看解析
参考答案：z=−0.6，p≈0.3543，阈值 0.5 下判正常

带走这一点：输入来自测量，标签来自外部已知结果，参数决定内部组合方式，预测是算出的待核对答案。

多个神经元与非线性

如果两类点怎样也不能用一条直线分开，怎么办？本讲让两个神经元先算中间数字，再看这种组合为何需要非线性。

一条直线分不开四个点

有两个只取 0 或 1 的输入。规则是：恰好一个输入为 1，标签才是 1。这叫异或，英文缩写 XOR。

输入已知标签规则核对
(0,0)0没有输入为 1
(1,0)1恰好一个为 1
(0,1)1恰好一个为 1
(1,1)0两个都为 1

画在正方形四角上，两个标签为 1 的点占一条对角线，两个标签为 0 的点占另一条。任何一条直线，都无法把两组完全分到两侧。

因此，继续微调第 1 讲那条直线，并不能完成这个任务。需要改变计算方式，而不只是换一组数。

隐藏层先提供新的中间信息

我们在输入与最终输出之间，加入两个计算单元。它们组成隐藏层：“隐藏”只表示位于中间，数值仍然可以查看。

  • 隐藏单元：接收输入，用自己的参数计算一个中间结果。
  • 激活：某个单元为当前输入算出的结果。换输入后通常会变，不是保存在模型中的权重。
  • 中间特征：后续计算可以使用的新信息；这里就是两个隐藏单元给出的数。

先看一种简单的激活函数 ReLU：负数改成 0，正数原样保留。于是 −1→0，0→0，1→1。

非线性在这里可以先理解为“不能用同一条直线描述整段变换”。ReLU 在 0 处有折角：左右两段使用不同的变化规则。

两步算出 XOR 的答案

下面的参数由我们手工选好，先研究它能否算对。设输入和为 t=x₁+x₂，然后：

  1. 隐藏层：h₁=ReLU(t)，h₂=ReLU(t−1)。
  2. 输出层：s=h₁−2h₂；分数 s≥0.5 判为 1，否则判为 0。
输入h₁h₂s / 预测
(0,0)000 / 0
(1,0)101 / 1
(0,1)101 / 1
(1,1)210 / 0

以 (1,1) 为例：输入和为 2，两个隐藏值是 2 和 1，最终 2−2×1=0。这里的 s 是分数，没有转成概率。

关键在第二个单元：输入和不超过 1 时，它输出 0；超过 1 后，它开始参与减法。分数因而可以先升后降。

关闭 ReLU，哪一步变了？

把两处 ReLU 改为直接传递，同一组参数就会算出：s=(x₁+x₂)−2(x₁+x₂−1)=2−x₁−x₂。

四点分数变为 2、1、1、0。输入 (0,0) 现在被判为 1，原因是第二个隐藏值 −1 不再被截成 0。

只做加权求和，叫线性变换；再加偏置，叫仿射变换。多个这样的层仍能合成一次仿射变换，单靠叠层无法突破直线分界的限制。

  • 加宽：增加同一层的单元数。
  • 加深：增加前后串联的层数。

本例证明“存在一组参数能完成 XOR”。它没有证明训练一定能找到这组参数，也没有证明 ReLU 在所有任务中都比 sigmoid 好。

为什么新的特征有用？

把四点画到隐藏特征平面

以 h₁、h₂ 为坐标，四个输入变成 (0,0)、(1,0)、(1,0)、(2,1)。两个正类重合在 (1,0)，直线 h₁−2h₂=0.5 就能分开它们。

原坐标难以区分的关系，经过中间变换，可以变得容易。这就是隐藏特征的一种用途。

也会丢失区别：两个输入若得到完全相同的隐藏值，后续仅靠这些值就不能区分它们。本例希望它们同类，所以没有造成问题。

判断自己是否理解时，试着说明：第二个隐藏单元在什么条件下开始输出正数，这个数又怎样改变最终分数。

展开最小公式与数值关系

ReLU：ReLU(z)=max(0,z)，即取 0 与 z 中较大的数。

为什么任意一条直线都无法完成 XOR？

把阈值并入偏置，用 w₁x₁+w₂x₂+b≥0 判为 1。两个正类要求 w₁+b≥0、w₂+b≥0。

两式相加，得到 w₁+w₂+2b≥0。两个负类却要求 b<0、w₁+w₂+b<0，相加得到同一个量小于 0，矛盾。

关闭 ReLU 的实验只说明那一组参数失败；这个证明则覆盖了所有单一直线。两种证据解决的问题不同。

为什么没有非线性的层能合并？

(xW₁+b₁)W₂+b₂ = x(W₁W₂)+(b₁W₂+b₂)。

把 W₁W₂ 看成新权重，把 b₁W₂+b₂ 看成新偏置，就又得到一次加权求和加偏置。加入非线性后，一般不能这样合并。

THE EXPERIMENT

开关一次非线性

实时计算 · 使用上文手工设置的参数，不执行训练。

先预测再操作：先点 (1,1) 算出两个隐藏值，再关闭 ReLU，指出第一个变错的样本。

h₁=0，h₂=0，s=0，类别 0。
为什么调一条直线始终不够？

两正类点的分数和必须不小于 0；两负类点的分数和必须小于 0。但这两个和都等于 w₁+w₂+2b，产生矛盾。把阈值吸收到 b 后，对任意直线都成立。

实验解释与可验算的对照
设置四点分数哪些点错了
开启 ReLU0、1、1、0全部正确
关闭 ReLU2、1、1、0(0,0) 被错判为 1

参数保持相同。不同来自隐藏值 −1 是否会变成 0；这是当前表达式的真实计算，没有进行训练。

换一道题，检查理解

1. 把十个只有加权求和与偏置的层串起来，会自动解决 XOR 吗？
查看解析
参考答案：不会，它们仍能合并成一个仿射变换

只有加权求和与偏置时，多层仍能合并成一次同类计算（仿射变换），仍受单一直线的限制。

2. 本讲四点全部正确，已经证明了什么？
查看解析
参考答案：存在这组能表达 XOR 的手工参数

这组手工参数算对了四个点，证明它能表达 XOR；怎样通过训练找到参数，以及新数据表现怎样，还要分别检验。

带走这一点：隐藏层先算中间特征；ReLU 的分段规则让组合产生新的形状。能表达一个答案，与训练能找到答案，需要分别判断。

LESSON 03 / 28

从连线图到向量、矩阵与张量

一台设备有两个数字，四台设备就有四组。怎样把这些数字排整齐，让同一个网络成批计算，同时不弄混参数与结果？

先读懂数字怎样排列

一条样本就是一次需要处理的记录；一项特征就是其中一种输入信息。设备案例里，一条记录包含温度与振动两个特征。

叫法白话含义本例
标量一个数振动指标 0.3
向量按顺序排的一组数一台设备的 [0.8,0.3]
矩阵排成行与列的一张数表三台设备：3 行、每行 2 个指标

本课约定每行一条样本，每列一种特征。矩阵的“形状”写成行数×列数：3×2 就是 3 行、2 列。

新增设备会多一行，新增传感器指标会多一列。先认清每条轴在数什么，再开始乘法。

把三条神经元账单并排看

2→3→1 表示两个输入、三个隐藏单元、一个输出单元。三个隐藏单元都收到输入 (0.8,0.3)，但使用不同参数。

这种每个单元都接收上一层全部结果的层，叫全连接层。这里每个隐藏单元都使用两项输入。

隐藏单元先做乘加经过 ReLU
10.8×1+0.3×0+00.8
20.8×0+0.3×1+00.3
30.8×(−1)+0.3×1+10.5

输出层使用权重 [1,−1,0.5] 和偏置 0，再算 s=0.8−0.3+0.5×0.5=0.75。接 sigmoid 后，输出约为 0.6792。

隐藏值 [0.8,0.3,0.5] 是本条输入的激活；输出权重 [1,−1,0.5] 是参数。数字偶尔相同，也不代表角色相同。

矩阵只是把同一批乘法写紧凑

把输入排成 X，把第一层权重排成 W。W 的每一列对应一个隐藏单元，列里放它使用的两个权重。

输入 X：1×2权重 W：2×3偏置 b：1×3
[0.8, 0.3]第一行 [1, 0, −1]
第二行 [0, 1, 1]		[0, 0, 1]

一行乘一列：将对应项相乘后相加。例如 X 乘 W 的第 3 列，再加第 3 项偏置，就是 0.8×(−1)+0.3×1+1=0.5。

三个单元一起写成 H=ReLU(XW+b)。H 是三项隐藏激活组成的表，并没有换成另一种算法。

多条样本一起算时，相同偏置会加到每一行。这种按约定重复使用的写法叫广播。

样本变多，参数仍然共享

批次是这一次一起处理的样本组，大小记作 B。每条样本用同一份权重，分别产生自己的隐藏值。

样本数 B输入 X隐藏值 H模型参数数

44×24×313

13 从哪里来？第一层有 2×3=6 个权重和 3 个偏置；输出层有 3 个权重和 1 个偏置：6+3+3+1=13。

矩阵乘法的接线检查：(B×2)×(2×3)→B×3。中间的两个 2 必须匹配；若输入改成 3 项特征，旧 W 不能直接接入。

本例 ReLU 不增加可训练参数。不要把“这个操作没有参数”扩大成“所有网络层都没有参数”。

图片和张量，也先看轴的含义

把图片看成许多小格，每格叫一个像素。灰度图每格只用一个数记录明暗，所以 4×4 图有 16 个亮度值。

按从左到右、从上到下的顺序把这些值排成一行，叫展平；第 2 行第 3 列对应向量第 7 项。

展平保存了像素值，但普通全连接层不会自动利用“哪些像素相邻”的结构。下一阶段的卷积会专门利用它。16 项像素也不能直接接入这个只收 2 项输入的网络。

张量比矩阵多在哪里？

张量可以先看成沿多条轴排列的数字。比如一批彩色图像，有样本、高度、宽度、通道四条轴。

通道可以分别存放红、绿、蓝等分量；不同软件可能把通道轴放在不同位置。因此读形状时，必须同时看每条轴的说明。

展开最小公式与数值关系

本课形状约定：X:B×2，W:2×3，b:1×3，H:B×3。输出层权重为 3×1，输出为 B×1。

把第二条设备也完整算一遍
  1. 输入：(0.2,0.1)，参数与第一条完全相同。
  2. 隐藏值：(0.2,0.1,−0.2+0.1+1)=(0.2,0.1,0.9)，ReLU 后保持不变。
  3. 输出：s=0.2−0.1+0.9×0.5=0.55，sigmoid 输出约 0.6341。

如果矩阵结果与逐单元计算不一致，先检查行列约定、偏置加在哪里，以及是否经过了激活函数。

怎样衡量预测好坏

模型给出答案后，怎样判断有没有进步？只看类别是否正确还不够，我们还需要一个衡量预测与目标差距的数字。

先预测，再拿标签核对

继续设备案例：模型先使用温度、振动和内部参数预测；随后，用人工检修给出的标签核对。标签是核对依据，不是本例预测时使用的测量输入。

损失是按约定公式算出的“预测与目标有多大差别”。训练希望让它变小；不同任务可以选择不同公式。

先看一个独立的数值预测任务：目标为 2。如果预测为 1，平方误差 (1−2)²=1；预测改成 1.5，误差变为 0.25。

这种直接预测数值的任务叫回归。预测 2.5 的平方误差也为 0.25，因为它与目标的距离同样是 0.5。

分类损失看正确类别得到了多少概率

分类是从几个类别中选答案。假设类别为 A、B、C，正确标签是 B，模型分别给出三个非负概率，合计为 1。

一种常用损失叫交叉熵。在这里，只需取正确类 B 的概率 p，再算 −ln(p)：给正确答案的概率越低，损失越大。

正确类 B 的概率交叉熵损失怎样理解
0.2约 1.6094给正确答案的机会较少
0.6约 0.5108比上一种更接近目标
0.9约 0.1054给正确答案较高概率

ln 是自然对数，这里先用它作一种计分刻度。操作实验时，会按固定比例分配其余类别的概率，确保三项合计仍为 1。

都答错，损失仍可能下降

准确率是正确次数除以样本总数。对单条样本，它只记录选对还是选错；交叉熵还会区分给正确类多少概率。

概率 (A,B,C)选最高概率的类别标签为 B：对错 / 损失
(0.60,0.30,0.10)A错误 / 约 1.2040
(0.50,0.45,0.05)A错误 / 约 0.7985

两次都选 A，但 B 从 0.30 提高到 0.45。因此，类别还没翻转，损失已经能反映改善。

较低损失不保证所有使用目标都改善。比如异常很少时，全部猜正常也可能有较高准确率；选指标还要考虑哪些错误最重要。

网络分数怎样变成一组概率？

网络给各类的原始分数叫 logit，多个分数称 logits。它们可以为正或负，不要求相加等于 1。

softmax 把这些分数转换为一组和为 1 的概率。一个可核对的例子是：

  1. 原始分数：(ln2,0,0)。
  2. 各自取指数：得到 (2,1,1)，都是正数。
  3. 除以总和 4：得到 (0.5,0.25,0.25)。

这一步叫归一化：把数值调整到约定的尺度。输出具备概率格式，仍不代表它已经通过可靠性检验。

损失怎样进入学习过程

现在可以把训练流程接起来。每一步各有职责：

  1. 预测：用当前参数处理训练输入。
  2. 比较：拿标签与预测计算损失。
  3. 求变化率：算出参数微小变化会怎样影响损失。这组变化率叫梯度，反向传播负责高效计算它。
  4. 更新：优化器按更新规则调整参数，再重新预测，检查实际效果。

损失很大，并不直接告诉我们每个权重该加多少。下一讲先解决变化方向与步长，第 6 讲再拆开反向传播。

展开最小公式与数值关系
  • 回归平方误差：L=(ŷ−y)²。y 表示目标，ŷ 表示预测值。
  • 单标签分类交叉熵：L=−ln(p正确类)。
  • 准确率：正确预测数 ÷ 样本总数。
  • softmax：pᵢ=ezᵢ/Σⱼ ezⱼ；Σ 表示把各项加起来。
概率为 0 时，损失为什么不能随便填一个数？

当正确类概率越来越接近 0，−ln(p) 会不断增大；p=0 时没有有限的损失值。不能把任意大的有限值写成精确答案。

实际程序可使用稳定公式避免数值溢出，但这个数学边界不变。本页滑块避开了概率为 0。

十条样本的平均损失，怎样变化？

假设一条样本给正确类的概率从 0.2 升到 0.4，但仍答错；另外九条都不变。准确率不变，这条损失却从约 1.6094 降到 0.9163。

十条平均后，损失下降约 (1.6094−0.9163)/10=0.0693。反过来，答对的一条也可能因正确类概率从 0.9 降到 0.6 而损失增大。

读成绩时先确认：它是单条损失、集合平均损失，还是整个集合的准确率。

1. 两个模型准确率相同，交叉熵损失一定相同吗？
查看解析
参考答案：不一定，给正确类别的概率可以不同

准确率只看最终类别是否选对；交叉熵还看给正确类别的概率，所以准确率相同，损失可以不同。

2. 反向传播在训练闭环里负责什么？
查看解析
参考答案：计算损失对参数的梯度，供优化器使用

反向传播计算“各参数微小变化会怎样影响损失”，得到梯度。优化器随后使用它更新参数，新预测还要重新向前计算。

带走这一点：准确率看选对多少次，损失按公式衡量预测与目标的差距。训练先求损失的变化率，再按规则更新参数。
