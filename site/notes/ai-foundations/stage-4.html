LESSON 13 / 28

文字怎样变成网络能处理的数字？

分成哪些片段、为片段编号、从表中取向量，是三个不同步骤。先把它们拆开，才能理解模型读到的究竟是什么。

Token 不一定是一个字，也不一定是一个词

分词器（Tokenizer）按特定规则把文本转成若干处理单位，称为 Token。中文、英文、数字、空格和标点可能采用不同切分方式；一个 Token 可能对应整个词、一部分词、一个字符，或字节片段。因此不能只数汉字或英文空格，就精确知道某个模型会处理多少 Token。

真实切分取决于词表、规则、规范化设置和版本。本页使用只有四项的教学词表与明确的最长匹配规则：它不是任何商业模型的分词器。未知字符会单独标为“词表外”，不为它编造模型 ID。这样可以自由试输入，又不会把教学规则误认为真实模型表现。

ID 是查表地址，不是带大小意义的数值

教学词表规定 0=温度、1=偏高、2=正常、3=检查。“温度 正常”便对应 [0,2]。这里第一个 Token 的位置是 1，而 ID 是 0；第二个 Token 的位置是 2，而 ID 也是 2。位置表达顺序，ID 表达词表条目，两者不能混用。

ID 1 与 ID 0 相差更小，不代表它们的意思比 ID 3 更接近。如果把四项做一致的重编号，并同时重排嵌入表的行，词与向量的配对可以完全保持。编号本身没有温度、距离之类的连续数值含义，模型需要把编号映射成后续使用的表示。

Embedding 就是取出参数表的一行

嵌入表 E（Embedding）先设为 [[1,0],[0.8,0.6],[0.2,0.9],[0,1]]，形状为 4×2。ID 2 选出第三行 [0.2,0.9]；输入 [0,2] 变成 [[1,0],[0.2,0.9]]，形状是 2×2。查表时 E 没变，只是不同编号取出不同激活。

用 one-hot 向量 [0,0,1,0] 乘 E，也会得到同一行；实际实现不必真的造出巨大 one-hot。本例的八个数是人工设定，不能当作真实中文语义。真实嵌入通常通过训练学习；当序列从 2 个 Token 增加为 5 个，词表与维度未变，表仍有 8 个参数，输入激活则有 5×2 个数。

低维图有时会隐藏重要差别

设人工向量 A=[1,0,0]、B=[1,0,2]、C=[0.9,0.1,0]。在完整三维空间中，A 与 B 距离为 2，A 与 C 距离约为 0.141。若只画前两维，A 与 B 完全重合。二维图上的相近，可能是被删掉的维度隐藏了差别。

因此阅读词向量散点图时，要问采用了什么模型、哪个表示、哪种距离和投影方法。坐标轴通常不能直接叫“积极程度”或“性别”。近邻也可能是常在相似上下文出现的词，未必是同义词。word2vec 是学习静态词表示的历史入口，本页算例没有冒充它的训练结果。

查表向量相同，后续表示仍可不同

“我吃了一个苹果”和“苹果发布了新设备”中的同一片段，只有在分词器把它们切成同一个 Token 时，才会先查到同一个静态向量。后续网络结合周围内容处理它们，隐藏表示可以不同。这一步是计算上下文的结果，不能简单说“词表自动知道意思变了”。

不同表示也不保证模型每次都正确理解含义。我们先保留“查表 → 结合上下文的网络 → 新表示”这条因果链，下一讲用数列观察状态如何依赖前文，再逐步学习更完整的注意力机制。

展开最小公式与数值关系

教学查表：Token“正常” → ID 2 → E 的第三行 [0.2,0.9]。词表 V 项、嵌入 d 维时，E 的形状为 V×d；长度 T 的输入查表后形状为 T×d。

LESSON 14 / 28

RNN：用同一套网络逐步读序列

每来一个新输入，网络把它和已有状态一起计算。变化的是状态，复用的是同一组参数。

预测下一个 Token，可以先看成分类

语言模型的一项基本任务，是给定已见前缀，为下一个 Token 分配概率。假设“温度”之后三个候选“偏高 / 正常 / 请”的教学分布是 [0.6,0.3,0.1]，取最大概率会选“偏高”，按该分布采样也可能选“正常”。这些是人为给定的概率，尚未来自本页的 RNN。

新生成的 Token 可以接回前缀，再继续预测。模型分布不等于整个回答的正确率，更不保证事实真实。本讲只建立“序列输入可以接分类输出”的连接，完整训练目标与生成策略在后续语言模型阶段再展开。

只看最近几格，会遇到无法区分的输入

考虑受控任务 A · · · ? 与 B · · · ?：在问号处报告开头是 A 还是 B。如果系统只读最近三个位置，两条输入在可见窗口内完全相同，却需要不同答案。问题在于决定标签的信息没有进入当前可见输入，不能只用“训练还不够努力”解释。

加大固定窗口可以让更早内容变得可见，但会改变输入组织与计算开销。RNN 提供另一种组织：将此前计算留下的状态带到下一步。状态可以暂称随身笔记，但它实际是一组数，不是一段自动保存原文的文字。

一次更新：新输入与旧状态相加后过非线性

循环神经网络（RNN）的简单状态更新是 hₜ=tanh(Wₓxₜ+Wₕhₜ₋₁+b)。tanh 把结果压到 −1 与 1 之间。输入 x、旧状态 h 与参数 W、b 的角色不同：参数提供规则，状态是这条序列到当前为止算出的激活。

设 Wₓ=1、Wₕ=0.5、b=0、h₀=0，输入 [1,0,0]。第一步加权和为 1，h₁≈0.7616；第二步加权和约 0.3808，h₂≈0.3634；第三步加权和约 0.1817，h₃≈0.1797。把相同元素换成 [0,0,1]，前两步状态都是 0，最终状态约 0.7616。顺序不同，计算路径不同。

展开多个方块，仍然只有一份参数

把三个时间步画成三个方块，只是把重复使用同一个状态单元的过程展开，并不表示训练了三套网络。这个标量单元始终只有 Wₓ、Wₕ、b 三个参数；序列变成六步，增加的是输入、状态和计算次数。若接词表分类头，头的参数需要另外计数。

普通推理会不断更新 h，却不会仅因读到一句话就自动修改 W。只有执行训练更新，模型参数才改变。我们的权重是人工数值，能够说明顺序依赖，不能用最终状态大小给它标上“中文理解程度”或“记忆准确率”。

沿时间反传，仍是熟悉的计算图求导

若在末端接一个损失，较早输入要经过多次状态更新才影响它。训练时先将计算按时间展开，再从损失沿依赖关系求导；共享参数在每次使用处都有贡献，需要合并。这通常称为通过时间的反向传播（BPTT）。

反向传播不是把原句倒过来再读一次，也不让生成过程偷看未来。较长依赖路径需要连乘更多局部导数，因此较早位置的影响可能变得很小或很大。下一讲把这一困难与选择性保留状态联系起来，但先区分“前向状态缩小”和“反向梯度缩小”是两个不同定义。

展开最小公式与数值关系

hₜ = tanh(Wₓxₜ + Wₕhₜ₋₁ + b)。本实验 Wₓ=1、b=0、h₀=0。单个状态更新的局部导数 ∂hₜ/∂hₜ₋₁ = Wₕ(1−hₜ²)。

THE EXPERIMENT

逐步读取，比较先后顺序

实时标量 RNN 前向与导数计算 · 参数人为设定，未训练。

先预测再操作：先逐步读取 [1,0,0]，再将非零输入放到最后；比较最终状态并确认参数数量没有变。

控制发生变化时回到 h₀；可逐步展开。时间步表示输入顺序，与页面播放速度无关。

实验解释与可验算的对照

打印验算：默认 [1,0,0] 的 h 为 [0.7616,0.3634,0.1797]；[0,0,1] 的 h 为 [0,0,0.7616]。两条序列与六步序列都共享同一组三个状态单元参数。Wₕ=0 时旧状态不参与更新；第一步的 1 到最后的状态贡献为零。这说明特定计算规则的限制，不是训练后模型性能记录。

第一步 h₁=0，第二步加权和为 1，tanh(1)≈0.7616。

查看解析

LESSON 15 / 28

LSTM 与 GRU：选择保留、写入和读出

保留旧信息、加入新内容、暂不输出，是不同操作。门控用连续数值调节这些操作的强度。

长路径上的导数乘积，可能很小也可能很大

链式法则让一条依赖路径的局部导数相乘。在理想化标量例中，十个导数都是 0.5，乘积约 0.000977；若都是 1.5，乘积约 57.665。这说明较早位置的一点变化，对末端损失的局部影响可能非常弱，也可能非常强。

真实 RNN 包括矩阵、非线性和多条路径，不能用这个固定乘数推算所有模型。前向状态幅度衰减和反向梯度消失也不是同一个定义。梯度裁剪能限制过大的梯度，却不能凭空恢复已经很小的梯度。门控提供另一种组织状态更新的方法。

LSTM 把保留与写入分开

长短期记忆网络（LSTM）保留单元状态 c，并计算输出状态 h。先看核心更新 cₜ=fₜ·cₜ₋₁+iₜ·候选ₜ：遗忘门 f 决定旧状态保留多少，输入门 i 决定候选写入多少。这里的乘法是逐元素乘法，门通常是 0 到 1 的连续值，并不只有开或关。

设旧 c=0.8，f=0.9，i=0.2，候选=0.5。保留贡献是 0.72，写入贡献是 0.10，新 c=0.82。再用输出门 o=0.5 计算 h=o·tanh(c)，得到约 0.3375。候选可以为负，状态的某个维度也不必恰好对应人能命名的一个概念。

不读出，不等于已经清空

设一个教学任务把 A 写成 c=1，B 写成 c=−1。处理中间占位符时，如果人工规定 f=1、i=0，旧 c 可以保持；若改为 f=0.8、i=0，初始 1 在十步后变成 0.8¹⁰≈0.1074。这是规则可复核的前向结果，不是模型已经学会长记忆的证据。

现在固定 c=1，只把输出门 o 设为 0，则 h=0，但 c 仍为 1。恢复 o 后仍能读出。因此内部保留、写入和当前读出应该分开观察。f=1 是便于计算的理想极限；有限输入下的 sigmoid 门通常不会精确等于 1，实际还会遇到泄漏与干扰。

真实门值来自可训练计算

真实 LSTM 会将当前输入 x 与旧隐藏状态 h 送入带参数的计算，再经 sigmoid 得到门值。候选通常经过 tanh。门的参数从任务损失中学习，所以“模型决定保留什么”必须落实到这个计算过程，不能把门画成自主理解重要性的开关。

下面的滑块只负责解释门的作用。若要比较训练好的 RNN 与 LSTM，应说明任务、训练长度、数据划分、参数与随机种子，并查看训练长度之外的成功与失败。人为 f=1 的演示不能证明无限记忆，高门值本身也不能证明模型存储了某个可解释概念。

GRU 用另一种门控混合状态

门控循环单元（GRU）常用一条 h 状态，而 LSTM 区分 c 与 h。这里采用 h=(1−z)·旧h+z·候选 的记号：z 越大，越采用候选。旧 h=0.8、候选=−0.2、z=0.25 时，结果为 0.75×0.8+0.25×(−0.2)=0.55；z 从 0 到 1 时，输出从 0.8 变到 −0.2。

GRU 的重置门还会影响候选如何使用旧信息。不同资料可能把 z 的方向写反，读公式比只记门名更可靠。部件较少不意味着所有任务上更快或更好，也不能说 LSTM 总比 GRU 记得更久；这些比较取决于具体设置与测量。

展开最小公式与数值关系

cₜ = fₜ·cₜ₋₁ + iₜ·候选ₜ；hₜ = oₜ·tanh(cₜ)。
本课 GRU 记号：h = (1−z)·旧h + z·候选。

THE EXPERIMENT

让状态保留、写入，或者暂不读出

实时人工门控计算 · 不是训练后 LSTM 的门值记录。

先预测再操作：先复核 c=0.82；只把输出门设为 0，检查 c 是否变化；再比较 f=1 与 f=0.8 的十步保留。

保留对照独立设置：初始 c=1、占位期间 i=0，使用上方 f；不使用上方“旧 c、候选、输入门”。

实验解释与可验算的对照

打印验算：0.9×0.8+0.2×0.5=0.82，0.5×tanh(0.82)≈0.3375。只改 o=0 后 h=0，c 仍为 0.82。独立保留例初始 1、i=0：f=1 时十步后仍 1；f=0.8 时约 0.1074。GRU 示例 z=0.25 得 0.55。理想梯度路径十步：0.5¹⁰≈0.000977，1.5¹⁰≈57.6650。

换一道题，检查理解

1. 旧 c=0.6、f=1、i=0、o=0，得到什么？
查看解析
参考答案：c=0.6，h=0

没有写入且完整保留，所以 c 不变；输出门关闭仅使 h 为零。

2. 真实模型的门值来自哪里？
查看解析
参考答案：输入与旧状态经过可训练参数计算

带走这一点：LSTM 分开控制旧状态、新写入和读出；门值是计算结果，人工理想保留不是无限记忆的证明。

LESSON 16 / 28

Seq2Seq 与注意力：生成时回头读取输入

生成第一个位置和第三个位置时，可能需要不同的信息。注意力让当前步骤按一组权重读取源序列的表示。

编码与解码，是两个职责

序列到序列（Seq2Seq）把一段输入转换为一段输出。以人工分块的“温度 偏高”→“temperature is high”为结构示例：编码器先读取两个源位置，解码器从开始标记出发，逐步产生三个目标单位，最后生成结束标记。输入和输出长度可以不同。

这个英文例句是给定的目标说明，并非前面手设网络真实翻译出来的结果。Encoder 与 Decoder 是职责名称，也可以由循环网络实现，并不专属于 Transformer。两者可以有不同参数，不应只因为画成相似方块就默认共享。

固定摘要的困难，不能简化成能装几个词

简单基线把编码器的最终状态交给解码器。无论源序列长两步还是六步，传递的都是一个固定维度向量。早期内容仍可能影响这个向量，但都需要经它传到生成端，这会给表示与学习造成困难。

这不意味着一个 d 维向量严格只能装 d 个词。向量是连续数值，信息保留还与编码方式、精度、干扰和训练有关。注意力采用另一个组织：保存所有源位置的表示，在每个输出步骤重新读取它们。序列更长，可直接读取的源向量数量随之增加。

先计算一次加权读取

给定源向量 v₁=[1,0]、v₂=[0,2]、v₃=[1,1]，权重分别为 [0.2,0.5,0.3]。三项贡献依次为 [0.2,0]、[0,1]、[0.3,0.3]，相加得到上下文 c=[0.5,1.3]。如果权重改成 [1,0,0]，结果就是 [1,0]。

混合的是向量中的数，不是按比例剪碎文字；权重 0.5 也不是答案有 50% 正确率。本例的非负权重和为 1，所以结果是一个加权平均。这里 v 只是待汇总源表示的记号，下一阶段引入 Value 投影时会明确切换到新的计算例子。

权重可以由分数归一化产生

设某个目标位置对三个源位置的教学匹配分数是 [0,ln2,ln3]。逐项取指数得到 [1,2,3]，再除以总和 6，softmax 权重就是 [1/6,1/3,1/2]。读取同样的源向量，得到 [2/3,7/6]≈[0.6667,1.1667]。只改一个分数，分母也变化，所以所有归一化权重都会随之改变。

真实 Seq2Seq 注意力通常根据当前解码状态与各源位置表示，经可训练打分函数算出分数。当前步骤变了，所需读取也可能变化。本页使用人工分数验证 softmax 和加权和，没有宣称复刻某个训练好的翻译器，也未提前混入下一讲的 Q/K/V 投影。

只看注意力图，无法读出完整答案

保持权重 [0.2,0.5,0.3]，只把 v₂ 从 [0,2] 改成 [0,4]，上下文便从 [0.5,1.3] 变为 [0.5,2.3]，而权重图一模一样。可见它只呈现读取比例，还缺被读取的内容与后续计算。某位置权重高，并不自动构成因果解释，也不能直接翻译成模型“正在想这个词”。

这里是目标序列读取源序列的表示。注意力早于 Transformer；下一阶段的自注意力则让同一序列中的位置读取本序列的表示。先把“权重乘向量，再求和”牢牢记住，再问权重怎样由当前位置和可读位置共同计算出来。

展开最小公式与数值关系

c = α₁v₁ + α₂v₂ + α₃v₃；αⱼ≥0，Σαⱼ=1。
softmax：αⱼ = exp(sⱼ) ÷ Σexp(sᵢ)。实现先减去最大分数，结果等价且更稳定。

THE EXPERIMENT

权重与向量，分别改变什么？

实时 softmax 与加权和 · 分数和向量人为设定；无真实翻译输出。

先预测再操作：默认手算 [0.5,1.3]；只把第二个向量末项改成 4；再切换分数模式，检查所有权重一起变化。

直接权重全为 0 时没有可归一化的总和，会提示修正；不会偷偷把无效输入当作模型结果。权重图表示读取比例，横轴为 0–100%。

实验解释与可验算的对照

打印验算：默认三项贡献 [0.2,0]、[0,1]、[0.3,0.3]，总和 [0.5,1.3]；v₂ 改成 [0,4] 后总和 [0.5,2.3]，权重不变。只读源 1 得 [1,0]。分数 [0,ln2,ln3] → 权重 [1/6,1/3,1/2] → 上下文 [2/3,7/6]。将源向量换位置而不对应换权重，一般会改变结果。

换一道题，检查理解

1. v₁=[2,0]，v₂=[0,2]，权重 [0.25,0.75]，上下文是多少？
查看解析
参考答案：[0.5,1.5]

两个向量分别乘对应位置权重，再逐维求和。

2. 权重图相同，就能确定后续输出完全相同吗？
查看解析
参考答案：不能，还需要源向量和后续计算

同样的权重读取不同向量会得到不同上下文；注意力比例只是计算的一部分。

带走这一点：注意力按当前需要加权读取源表示；理解输出必须同时看权重、向量内容与后续网络。
