STAGE 04 · 文字变成数值，状态连接前后

序列模型与注意力起点

文字先变成可查表的处理单位，再变成数值向量。RNN 让前面留下的状态向后传；门控调节保留与写入；注意力让每个输出步骤重新读取需要的源信息。

  • 计算注意力加权和，理解权重图的边界

LESSON 13 / 28

文字怎样变成网络能处理的数字？

“温度正常”不能直接与权重相乘。先把文字分块、给每块编号，再取出对应的一组数。分块、编号、向量各做一件不同的事。

第一步：文字先分成哪些处理单位？

网络先按一套规则把文字分成若干块，每块叫一个Token。负责切分的程序叫分词器（Tokenizer），它需要配套的规则和词表。

例如本页教学规则把“温度正常”分为“温度”和“正常”。这是两个 Token，虽然原文有四个汉字。

  • Token 不一定是词：实际分词可能得到完整词、词的一部分、字符或字节片段。
  • 规则不同，切分可不同：不能只数汉字或空格，就断定某个真实模型用了多少 Token。
  • 本页范围很小：词表只有“温度、偏高、正常、检查”。从左向右优先匹配最长条目，空白略过；未知字符单独标为词表外。

因此输入“苹果”时，本页不会编造实际模型的编号或向量。这是一个规则公开的教学分词器。

第二步：ID 指出是哪一项，向量提供计算用的数

词表是可处理条目的清单；ID是条目编号。编号只用于找到条目，不能直接当作含义的大小。

找到条目后，取出它对应的一组有顺序的数，这组数叫向量。[0.2,0.9] 有两项，称为二维向量；它们将进入后续乘加运算。

教学 ID词表条目对应的手设二维向量
0温度[1,0]
1偏高[0.8,0.6]
2正常[0.2,0.9]
3检查[0,1]

保存这些向量的参数表叫嵌入表（Embedding）。根据 ID 取一行，叫嵌入查表。真实表通常通过训练学习；本表数字由人设定，不代表真实词义。

  1. “温度 正常”先变成 ID 序列 [0,2]。
  2. 从表中取第 1、3 行，得到 [[1,0],[0.2,0.9]]。
  3. 两个 Token，各两个数，所以输出形状为 2×2。查表没有修改表内参数。

不要混淆：位置、编号和参数

概念回答什么问题在“温度 正常”中的例子
位置在这句话中排第几个？“正常”排第 2 个
ID对应词表哪一个条目？“正常”的 ID 是 2；ID 从 0 开始
向量取出哪些数来参与运算？[0.2,0.9]
嵌入表参数长期保存什么计算材料？全表 4×2，共 8 个数

句子变长：5 个 Token 会取出 5 行向量，但词表没变，仍只有 8 个参数。

编号变了：若同时一致地重编号、重排表行，同一个词仍可取到原向量。ID 差得近，不代表意思近。

为什么查表也可以写成矩阵乘法？

用 [0,0,1,0] 表示“只选第三行”。它乘嵌入表 E，会得到 0×第1行+0×第2行+1×第3行+0×第4行，即 [0.2,0.9]。

这个只有一个 1 的选择向量叫 one-hot。它与本次直接查表等价，实际程序不必真的创建很长的 one-hot 向量。

取到向量之后，还要结合前后文

“我吃了一个苹果”与“苹果发布了新设备”中的“苹果”，如果被切成同一个 Token，最初会查到同一行向量。

后续网络的任务：再结合周围内容，计算适合这个位置的新表示。因此“查表向量相同”不等于“经过上下文处理后的结果相同”。

新表示也不保证每次都正确理解词义。下一讲先用短数列，看前文怎样通过状态影响后续计算。

向量图为什么可能误导人？

人工向量 A=[1,0,0]、B=[1,0,2]、C=[0.9,0.1,0]。在三维中，A–B 距离为 2，A–C 约为 0.1414。

若只画前两维，A 与 B 就重合了。投影是把表示压到较少维度；被丢掉的维度可能藏着重要差别。

看词向量图，要问模型、距离和投影方法。近邻未必是同义词，坐标也不必有“积极程度”等固定含义。word2vec 是学习静态词表示的历史入口。

展开最小公式与数值关系

表的形状：词表有 V 项、每个向量有 d 个数，嵌入表为 V×d。V、d 固定，表的参数量就是 Vd。

本次输出：长度为 T 的 Token 序列，查表后得到 T×d 个数。T 改变的是本次取出的行数，不是表的行数。

例：ID 2 → 表的第三行 [0.2,0.9]；“温度 正常” → [0,2] → [[1,0],[0.2,0.9]]。

查看解析

LESSON 14 / 28

RNN：用同一套网络逐步读序列

读到句尾时，怎样仍让开头影响结果？RNN 每读一个新输入，就用“新输入＋已有状态”算出下一份状态。

为什么需要把前面留下的信息带过来？

任务很简单：读 A · · · ? 或 B · · · ?，到问号时报告开头的字母。如果只看最近三个位置，两串内容看起来完全一样，答案却不同。

缺的是可见信息：不是训练再努力一点就能区分相同输入。可以扩大窗口，也可以把此前计算留下的结果传到后面。

后一种结果叫状态：一组随序列更新的数。它能带来此前输入的影响，但不是完整保存原文的文字笔记。

RNN 每一步做什么？

循环神经网络（RNN）在每个位置重复同一个状态更新规则。“循环”指规则反复使用，不是网页动画，也不是不断重新训练。

量白话意思本例角色
当前输入 xₜ这一格新读到的数例如序列的第一个 1
旧状态 hₜ₋₁前面计算留下的数第一次从 h₀=0 开始
参数 Wₓ、Wₕ、b规定怎样组合两者本例为 1、0.5、0
新状态 hₜ合并后得到的数传给下一格继续使用
  1. 乘权重再相加：新输入×1 + 旧状态×0.5 + 0。
  2. 经过 tanh：将加权和压到 −1 与 1 之间；例如 tanh(1)≈0.7616。
  3. 向后传递：把这个结果作为下一步的旧状态。

tanh 是一种非线性函数，使更新不只是几次线性加法。先会沿着步骤算，不必背它的导数。

同样三个数，顺序不同会怎样？

固定上述参数，输入 [1,0,0]。计算时保留精度，下表只显示近似值。

步当前输入加权和新状态
111+0.5×0=10.7616
200+0.5×0.7616≈0.38080.3634
300+0.5×0.3634≈0.18170.1797

换成 [0,0,1]，前两步状态都是 0，最后才算 tanh(1)≈0.7616。元素相同，顺序不同，末态可以不同。

边界：这些参数由人设定，没有学过中文。状态值大，不意味着理解更好；它只是当前规则对这条数列的输出。

状态一直变，为什么不算一直在学习？

操作状态 h参数 W、b
读取下一个输入重新计算保持原值
把序列延长增加状态与计算步骤这个标量单元仍只有三个参数
执行训练更新用于计算损失与梯度优化器才会调整参数

把 RNN 展开成六个时间步的图，只是展示同一个单元用了六次，不是六套独立网络。若另外接输出头，头的参数需要另算。

怎样接到“下一个 Token”预测？

在状态后接一个分类头，为词表里的每项打分，就能把序列处理接到下一 Token 预测。

例如前缀“温度”的候选“偏高 / 正常 / 请”，假设概率为 [0.6,0.3,0.1]：选最大值会取“偏高”，按概率采样也可能取“正常”。

这是手设分布，不是本页 RNN 的语言输出。选出的 Token 可接回前缀；概率也不是整段回答的事实正确率，后面会专门讨论生成。

训练时为什么要“沿时间反向传播”？

把重复计算按时间展开，末端损失便依赖一串状态。反向传播沿这些依赖求导；同一个参数在不同时间步的梯度贡献需要相加。

这叫 BPTT，即通过时间的反向传播。它不是把句子倒着再读一遍，也不让生成时看见未来。

早期输入经过的状态步骤较多，局部导数会沿路径连乘。较早信息对损失的影响可能很弱或很强，下一讲再看门控怎样组织更新。

展开最小公式与数值关系

状态更新：hₜ=tanh(Wₓxₜ+Wₕhₜ₋₁+b)。下标 t 指第几个输入位置。

本例 Wₓ=1、Wₕ=0.5、b=0、h₀=0。每一步都使用同一套 W、b，只把 x 与旧 h 换成当前值。

供实验核对的局部导数：∂hₜ/∂hₜ₋₁=Wₕ(1−hₜ²)，表示旧状态微变时，新状态的局部变化率。

THE EXPERIMENT

逐步读取，比较先后顺序

实时标量 RNN 前向与导数计算 · 参数人为设定，未训练。

先预测再操作：先逐步读取 [1,0,0]，再将非零输入放到最后；比较最终状态并确认参数数量没有变。

控制发生变化时回到 h₀；可逐步展开。时间步表示输入顺序，与页面播放速度无关。

实验解释与可验算的对照
输入序列逐步状态（约）最终状态
[1,0,0][0.7616,0.3634,0.1797]0.1797
[0,0,1][0,0,0.7616]0.7616

参数共享：这些序列与六步序列都用同一组三个状态单元参数。

关闭旧状态影响：Wₕ=0 时，每一步只读当前输入；开头的 1 不再影响最后的状态。这是手设规则的结果，不是训练性能排名。

换一道题，检查理解

1. 使用默认参数读取 [0,1]，最终状态约是多少？
查看解析
参考答案：0.7616

第一步输入 0，从初始状态 0 得到状态 0。第二步输入 1，加权和为 1+0.5×0=1，最后 tanh(1)≈0.7616。

2. 将这条标量 RNN 展开至 20 步，会新增 20 套 Wₓ、Wₕ、b 吗？
查看解析
参考答案：不会，增加中间状态与计算次数

新增的是计算步骤与中间状态。同一个 Wₓ、Wₕ、b 被重复使用；只有执行训练更新，才会改变它们的值。

带走这一点：状态是此前输入留下的计算结果，参数是反复使用的规则。RNN 让前者逐步传递，让后者跨位置共享。

LESSON 15 / 28

LSTM 与 GRU：选择保留、写入和读出

某条信息需要留到句尾，新输入却不断到来。能否把“保留多少旧信息”“写入多少新信息”“现在输出多少”分开控制？

门不是开关，而是乘上一个比例

把一个数乘 0，就不让它通过；乘 1，就完整保留；乘 0.2，就保留两成。用这个比例调节信息传递，叫门控。

长短期记忆网络（LSTM）把内部保留的数 c 与当前输出的数 h 分开，再用几个门决定它们怎样更新。

部件白话作用调节什么
单元状态 c内部继续保留的数值供后续位置继续使用
遗忘门 f旧内容留多少乘旧 c；值越大，保留越多
输入门 i新内容写多少乘本步候选内容
输出门 o当前读出多少乘经过 tanh 的新 c，得到 h

候选是什么？本步准备写入的新数值。它可以为负；门通常在 0–1 之间。状态各维也不必对应人能命名的“记忆槽”。

算一遍保留、写入与读出

给定旧 c=0.8，遗忘门 f=0.9，输入门 i=0.2，候选=0.5，输出门 o=0.5。

  1. 保留旧值：0.9×0.8=0.72。
  2. 写入候选：0.2×0.5=0.10。
  3. 合成新状态：c=0.72+0.10=0.82。
  4. 当前读出：h=0.5×tanh(0.82)≈0.3375。

现在只把 o 改成 0：h 变为 0，c 仍是 0.82。暂时不读出，不等于已经清空内部状态。

门值是谁决定的？能保证一直记住吗？

本实验由你拖动门值，目的是看清作用。真实 LSTM 会根据当前输入、旧隐藏状态和可训练参数计算门值，再用 sigmoid 将它压到 0–1 之间。

也就是说，训练会调整“如何算门值”的参数，不是人永远逐步开关。一个门值高，也不能独自证明网络记住了某个可解释概念。

人工保留实验：初始 c=1，后续 i=0十步后的 c得到什么结论
每步 f=11理想规则可完整保留
每步 f=0.80.8¹⁰≈0.1074少量泄漏会随步骤累积

边界：这不是训练好的 LSTM 具有无限记忆的证据。f=1 是理想极限；有限输入下 sigmoid 通常不精确等于 1，实际还会有干扰。

GRU：用一个比例混合旧值与候选

门控循环单元（GRU）采用另一种更新结构，常用一条 h 状态。先看更新门 z：在本课记号里，它决定候选占多少，剩下比例留给旧状态。

旧 h=0.8，候选=−0.2，z=0.25：新 h=0.75×0.8+0.25×(−0.2)=0.55。

z采用什么新 h
0全部用旧值0.8
0.25旧值占 75%，候选占 25%0.55
1全部用候选−0.2

GRU 还有重置门，影响候选怎样使用旧信息。不同资料的 z 记号方向可能相反，需看公式；部件更少不保证所有任务上更好。

长路径为何会出现梯度消失或爆炸？

反向求导时，一条路径上的局部导数会相乘。十步都为 0.5，乘积约 0.000977；十步都为 1.5，乘积约 57.665。

前者说明早期微小变化对末端损失的局部影响很弱，后者说明影响可能很强。它与前面“c 的数值逐步变小”不是同一个定义。

真实网络还有矩阵、非线性和多条路径，不能用固定乘数预测全部行为。梯度裁剪限制过大梯度，不能恢复已经很小的梯度。

展开最小公式与数值关系

LSTM 写入：cₜ=fₜ×cₜ₋₁+iₜ×候选ₜ。旧贡献与新贡献分开计算，再相加。

LSTM 读出：hₜ=oₜ×tanh(cₜ)。向量版本在每个对应位置做这些乘法，不是点积求和。

本课 GRU：新 h=(1−z)×旧 h+z×候选。这里 z 越大，候选占比越高。

THE EXPERIMENT

让状态保留、写入，或者暂不读出

实时人工门控计算 · 不是训练后 LSTM 的门值记录。

先预测再操作：先复核 c=0.82；只把输出门设为 0，检查 c 是否变化；再比较 f=1 与 f=0.8 的十步保留。

保留对照独立设置：初始 c=1、占位期间 i=0，使用上方 f；不使用上方“旧 c、候选、输入门”。

实验解释与可验算的对照
要比较的操作结果
默认保留＋写入0.9×0.8+0.2×0.5=0.82
默认读出0.5×tanh(0.82)≈0.3375
只改 o=0h=0，但 c 仍为 0.82
独立保留例：初始 1，i=0f=1 时十步后为 1；f=0.8 时约 0.1074

反向路径对照：十步局部导数相乘，0.5¹⁰≈0.000977；1.5¹⁰≈57.6650。不要将导数乘积与前向状态值混为一谈。

查看解析

f=1 完整保留旧 c，i=0 不写新内容，所以 c=0.6。o=0 只让本次输出 h=0，没有清空 c。

LESSON 16 / 28

Seq2Seq 与注意力：生成时回头读取输入

把“温度 偏高”变成“temperature is high”时，生成不同位置可能需要不同线索。先保存输入各处的表示，再按当前需要读出一份数值摘要。

编码与解码：先读输入，再逐步写输出

把一个序列转换成另一个序列，叫Seq2Seq。这里的序列就是有顺序的一串处理单位；输入与输出不必一样长。

职责白话意思教学例子
编码器 Encoder读取源序列，计算表示读“温度”“偏高”两个位置
解码器 Decoder利用这些表示，逐步产生目标单位从开始标记起，生成三个英文单位，再生成结束标记

这两个名字表示分工，循环网络也可以承担它们，不专属于 Transformer；两边的参数也不必共享。

例句边界：词块和英文目标是人为给定的结构示例，不是前面手设网络真实翻译出来的结果。

为什么不只给解码器一份固定摘要？

简单做法是只把编码器的最后状态交过去。早期信息也可能在里面，但都要经过同一个固定维度向量，表示和学习会变得困难。

可读取的材料源序列从 2 个位置延长到 6 个解码时怎样使用
只保留编码末态仍交付一个固定维度向量所有信息须经这一个摘要传递
保留所有源位置表示可读向量从 2 个增加到 6 个每个输出步骤重新选择读取比例

注意力采用后面这种按需读取思路：给各源位置一个比例，将它们的数值表示加权合并。它不是“固定向量只能存几个词”的字数容量公式。

三个词：读取需求、权重、上下文

先不讨论复杂网络，明确一次读取需要哪三件事。

当前读取需求
这一步需要找什么信息，由当前解码状态参与决定。下一讲会用 Query（查询向量）表达读取需求；本讲先不计算 Q/K/V 投影。
注意力权重
各源位置在本次汇总中占的比例。例如 [0.2,0.5,0.3]，表示三份向量分别乘这些数。
上下文向量
加权相加后，实际交给当前解码步骤使用的数值摘要。它不是原始文本，也不是权重本身。

给定 v₁=[1,0]、v₂=[0,2]、v₃=[1,1]，计算如下。这里 v 只是“待读取的源向量”，不提前等同下一讲的 Value 投影。

源向量权重乘完后的贡献
[1,0]0.2[0.2,0]
[0,2]0.5[0,1]
[1,1]0.3[0.3,0.3]

最后逐维相加：第一维 0.2+0+0.3=0.5；第二维 0+1+0.3=1.3。因此上下文为 [0.5,1.3]。

权重怎样产生，为什么只看权重还不够？

真实模型用当前解码状态和各源表示计算匹配分数，再将分数变成读取比例。当前输出位置变了，需求与权重都可能变。

本例权重的约束：每项非负、总和为 1。混合的是向量中的数；0.5 是读取比例，不是答案正确率。

只改哪一项权重上下文
默认[0.2,0.5,0.3][0.5,1.3]
只读第一个源位置[1,0,0][1,0]
把 v₂ 改成 [0,4]仍为 [0.2,0.5,0.3][0.5,2.3]

最后两列说明：同一张权重图，也可以读出不同结果。还要知道被读取的向量与后续计算；权重高不能单独作为完整因果解释。

从分数算权重：一次 softmax

softmax 把一组分数变成非负、和为 1 的比例。给定教学分数 [0,ln2,ln3]；ln2 的意思是“取指数后得到 2”的数。

  1. 各项取指数，得到 [1,2,3]。
  2. 除以总和 6，得到 [1/6,1/3,1/2]。
  3. 乘上述源向量再相加，得到 [2/3,7/6]≈[0.6667,1.1667]。

只改一个分数，分母也变，所以所有权重可能变化。本页分数由人设定，演示读取计算，不是训练后翻译记录。

下一步：这里由目标序列读取源序列；自注意力则让同一序列的位置读取本序列的表示。注意力早于 Transformer。

展开最小公式与数值关系

加权读取：c=α₁v₁+α₂v₂+α₃v₃。v 是源向量，α 是对应位置的读取比例，c 是上下文向量；α 均非负且总和为 1。

从分数得到比例：αⱼ=exp(sⱼ)/Σexp(sᵢ)。s 是匹配分数，exp 表示取指数，Σ 表示把所有项加起来。

代码先从每个分数减去同一个最大值，再取指数。归一化结果不变，数值计算更稳定。

THE EXPERIMENT

权重与向量，分别改变什么？

实时 softmax 与加权和 · 分数和向量人为设定；无真实翻译输出。

先预测再操作：默认手算 [0.5,1.3]；只把第二个向量末项改成 4；再切换分数模式，检查所有权重一起变化。

直接权重全为 0 时没有可归一化的总和，会提示修正；不会偷偷把无效输入当作模型结果。权重图表示读取比例，横轴为 0–100%。

实验解释与可验算的对照

默认读取：三项贡献 [0.2,0]、[0,1]、[0.3,0.3]，逐维相加得 [0.5,1.3]。

改动结果
只读源 1[1,0]
保持权重，v₂ 改为 [0,4][0.5,2.3]
分数 [0,ln2,ln3]权重 [1/6,1/3,1/2]，上下文 [2/3,7/6]

换一道题，检查理解

1. v₁=[2,0]，v₂=[0,2]，权重 [0.25,0.75]，上下文是多少？
查看解析
参考答案：[0.5,1.5]

第一个向量贡献 [0.5,0]，第二个贡献 [0,1.5]。逐维相加，得到上下文 [0.5,1.5]。

2. 权重图相同，就能确定后续输出完全相同吗？
查看解析
参考答案：不能，还需要源向量和后续计算

权重只规定各向量乘多少。保持比例不变而改变源向量，汇总结果仍会改变；后续网络也继续影响最终输出。

带走这一点：读取需求决定怎样找，权重决定各处占多少，上下文是实际读出的向量。理解注意力，要把比例与被读取的内容一起看。

阶段检查：从文字走到一次读取

  1. 分清输入四步：“温度 正常”的 Token、ID、向量分别是什么？嵌入表与本次输出谁是参数？
  2. 解释状态：RNN 读下一格时，哪些数变化？为什么序列延长不新增一套参数？
