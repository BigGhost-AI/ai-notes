从语言模型到可用的助手

网络顶端的向量怎样变成候选词？文本怎样成为训练标签？示范和偏好怎样改变模型？新手册与精确计算又从哪里进入系统？这四讲把参数学习、逐步生成和外部工具接起来，并在每条连接上检查信息来源。

这一站，学会什么

  • 从隐藏向量计算词表分数、概率与损失。
  • 正确配对输入与下一 Token 标签，区分并行训练与逐步生成。
  • 区分预训练、SFT、偏好优化与 LoRA。
  • 跟踪一次有来源、有工具参数、可定位失败的助手流程。

LESSON 21 / 28

下一 Token 怎样变成一段回答

输出头给词表打分；训练把原文错开一位作为目标，生成则把刚选出的 Token 接回前缀。

词表头：向量还要再经过一次投影

设最终隐藏向量 h=[1,2]，输出矩阵的两行为 [1,0,−1] 和 [0,1,1]，偏置为零。完整玩具词表只有“正常、异常、〈结束〉”三项。乘法得到 logits=[1,2,1]，经 softmax 得概率约 [0.212,0.576,0.212]。目标为第二类时，负对数损失约为 −ln(0.576)=0.551。

尺寸为 1×2→1×3；一般是 1×d→1×词表大小。Attention 的 Value 与词表输出头是不同部件；注意力权重分配给来源位置，词表概率分配给候选 Token。模型给某词高概率，不意味着这句话在现实中正确。此处隐藏表示已完成最终归一化，人工头并没有接受语言训练。

原文自己提供标签，但要错开一次

切换到另一个完整四词词表：〈开始〉、设备、正常、〈结束〉。原句为“〈开始〉 设备 正常 〈结束〉”。输入三项“〈开始〉、设备、正常”，目标三项“设备、正常、〈结束〉”，垂直配对。看到设备的位置要预测正常，而不是再抄一遍设备。

每个位置都要遵守因果范围：第二个位置只读〈开始〉和设备，不能读输入中的第三项正常。训练时已知原文，所以多道预测题可以同时计算；各题仍只用自己的真实前缀。这不取消网络层之间的依赖。某些训练库内部会完成标签 shift，若外面再移一次就会错位两次。教学分词与特殊 Token 也不代表任何具体产品的分词方案。

从概率回到训练闭环

三道题的正确目标概率若为 0.5、0.25、0.8，对应损失是 0.6931、1.3863、0.2231，平均约 0.7675。第二道题对正确词最没把握，损失最大。只将其目标概率改为 0.5，平均损失变为约 0.5365；这是损失函数对数字的响应，不代表已把某个网络训练好。

真实闭环仍是前向求概率→计算平均损失→反向传播求参数梯度→优化器更新。梯度能传回此前的可训练部件，不只改变选错词对应的一列。本实验给定一个标量梯度检查 w←w−ηg，会清楚标明“给定梯度”，它不是完整 Transformer 的反传。

生成：前缀增长，题目也改变

普通自回归生成从最后位置的分布选一个 Token，把它加到前缀，再算下一个位置。未来 Token 还未确定，所以常规解码逐步进行，普通生成过程中参数不自动更新。玩具状态表给前缀“设备”分布 [0.6,0.3,0.1]；选正常或异常后，下一轮分布为 [0,0,1]，随后结束。这张表是人工设计的有限状态模型，不是训练出来的回答。

贪心直接选最大项。温度采样将 logits 除以正温度再归一化；对 [ln4,ln2,ln1]，温度 1 得 [4/7,2/7,1/7]，温度 0.5 得 [16/21,4/21,1/21]。低温更集中，但最高项本来错误时并不会因此正确。固定分布重复抽样 100 次用于观察频率；它冻结上下文，与前缀逐步增长是两个独立实验。固定随机种子使同设置可复现，有限样本频率仍不必恰等于理论概率。

预测概率、损失与选词不是一个按钮

同一个分布可以被用于两个不同环节：训练时读取正确目标对应的概率来求损失；生成时按照选词策略决定追加哪个候选。训练并不需要先随机抽出一个词，才知道正确目标概率有多大。生成时没有每一步现成的正确答案，也通常不计算这条回答相对于未知标准答案的训练损失。

这能解释一个常见疑惑：模型这次随机选了较低概率的词，并不意味着参数刚刚发生了变化；相同参数也可以通过不同随机数产生不同结果。反过来，同样一句最终文本也不证明模型参数相同，因为不同分布或不同模型都可能选出相同词。要复现实验，需要同时记录输入前缀、参数或人工状态表、选词设置和随机种子。

展开最小公式与数值关系

logits=hW+b；p=softmax(logits)；L=−ln p(正确目标)。

多位置平均：L=(L1+L2+L3)/3。采样温度 T>0 时 pᵢ=exp(zᵢ/T)/Σⱼ exp(zⱼ/T)；贪心单独处理，不做除以零。

LESSON 22 / 28

预训练：数据、目标与规模

参数量、独立数据、训练 Token 数和运算预算是不同的量。比较模型，需要先对齐任务与证据。

大规模训练延续同一个学习闭环

将上一讲的一个批次放大，仍然是读取文本、预测下个 Token、求平均损失、反传、更新。大规模训练额外需要组织许多数据批次、保存检查点、监控异常，并在独立验证数据上判断何时调整方案。网络结构与优化目标可以相同，而工程规模相差很大。

检查点保存某个训练时刻的权重状态，常还需要优化器等恢复信息。为了比较，至少记录模型结构与参数量、训练 Token 数、数据划分、随机种子和评估设置。它不是按文档页码存储的检索目录。参数可能记住部分文本，但从参数生成一句话不保证能准确找回它的出处。

数量增加，未必增加独立信息

假设有 12 张人工文档卡，其中三张是同一个文档的重复，另有一张损坏文本和一张混入的测试材料。原始文档数是 12，但按重复组去重后少于 12；总 Token 数也会变化。同一篇文章复制十次可以改变训练时的出现次数，不等于得到十份独立知识。

清理时要看组成：删除某类文档后，不同领域、语言、年份的比例会变。去重和去乱码是可明确运行的规则，但格式整洁不等于事实准确。粗糙的过滤也可能过度删除少数表达方式。测试材料若进入训练，即使测试分数变高，也出现了泄漏风险，不能作为泛化改善的充分证据。

预算相同，怎么分配仍是实验问题

使用代币预算 B=参数单位 P×Token 单位 D，预算上限 24，可以分为 (2,12)、(4,6)、(6,4)。三者乘积都为 24，但不能仅凭乘法知道哪种模型在手册问答上更好。参数更多不代表训练充分，数据更多也要看质量、分布、重复与优化过程。

真实训练开销还受架构、序列长度、硬件、实现与常数影响；本面板既不是实际报价，也不是性能预测器。计算最优缩放研究在明确实验条件下研究参数与数据的共同分配。论文得到的关系有适用范围，不能机械变成任何小任务、任何预算下的永恒最优公式。

读曲线：先读坐标和数据身份

一张训练曲线的横轴可以是训练步数或累计 Token 数，不能把动画播放秒数当作训练成本。纵轴为损失时，下降意味着对该数据分布和目标的预测改善，不直接意味着所有回答都可靠。还要分开训练损失、验证损失以及任务评价；某些变化可能只出现在其中一个指标。

本页给三组明确标为“教师构造”的数值：共同下降；训练下降而验证上升；预测损失下降而独立任务分数没有变化。它们练习如何解读证据，不属于任何真实模型成绩。选检查点用验证集，最终测试集保留到方案确定后。想公平比较两个模型，先写出五项清单：任务是什么，数据怎样划分，训练预算多少，推理设置是否相同，评价方法怎样执行。仅报模型参数量无法替代这些信息。

比较报告应当让别人能复查

一份有用的比较报告可以从一个具体任务开始，例如从未见过的手册段落提取型号与采样间隔。先固定题目和判分规则，再用相同推理设置运行待比较的检查点，分别记录正确、错误、缺少依据的样本。若只保留成功例子，读者无法判断失败边界；若两次使用不同题目，也难以知道变化来自模型还是题目难度。

报告不一定很长，但每个数字都应能回到其测量过程。数据卡片统计、教学预算和真实模型评价属于不同证据，不应被放在一起相加成为一个没有定义的“智能分数”。

展开最小公式与数值关系

本页代币预算：B=P×D，上限 24。它只说明资源分配的算术关系。独立文档数按公开重复组统计；训练 Token 数按实际保留卡片长度相加。

LESSON 23 / 28

从续写到按要求回答

示范告诉模型怎样回答，偏好比较告诉模型哪段更合适；可验证反馈则用明确规则检查结果。

监督微调：学习一份希望模仿的答案

普通文本预测可以学到许多模式，却不保证输入问题后就给出符合要求的助手回答。监督微调 SFT 将训练材料组织成请求和示范答案，例如“请根据 AQ-1 v2 手册回答采样间隔，并标来源”对应“间隔为 10 秒［D1］”。这些例子展示希望模仿的行为和信息组织。

底层仍用 Token 预测与损失。常见设置只对助手回答位置求损失，而提示部分提供上下文；这不是所有 SFT 的统一规定。示范的正确性、覆盖和风格都会影响训练。用户在聊天里补一句“请简洁”通常只是改变当前上下文，并没有因此启动监督微调。

偏好比较：先公开评判标准

同题两份教师构造答案：A 说“AQ-1 v2 的采样间隔为 10 秒［D1］”，B 说“BX-2 的采样间隔为 60 秒［D5］”。若题目问 AQ-1，B 即使语气流畅且自身引用正确，也答错了型号。按正确、相关、有依据的标准，应更偏好 A。

另一个答案对都正确且完整，只是一个简短、一个冗长。这时偏好标准中的表达效率会影响选择。标注数据记录问题、被选答案、未选答案与理由；它不是事实真理生成器。不同标注者可能有分歧，被喜欢、写得长或看似有推理过程，都不能替代事实核验。

RLHF 与 DPO：使用比较信号的两条路径

把语言模型分配候选概率的方式看作策略，输出一个 Token 或一段回答是不同粒度的动作，奖励是训练时评价结果的反馈。经典奖励模型式 RLHF 先用偏好对训练奖励模型，再对语言模型生成的回答评分，通过强化学习方法更新策略。奖励不是梯度，梯度也不是参数更新本身。

DPO 使用偏好对与参考模型，直接构造偏好目标来更新语言模型，通常无需单独训练一个显式奖励模型。它仍需要数据、目标和训练，并不是免训练的投票功能。两者是代表路径，不能把所有后训练画成固定的“先 SFT 再 RLHF 再 DPO”流水线，也不能在没有同基座、同题、同设置记录时捏造训练前后的效果提升。

学习目标与参数调整方式分开看

LoRA 描述如何调整参数：冻结基础大矩阵，训练两个小矩阵形成低秩增量。四乘四基础矩阵含 16 个数；秩 1 增量由 4×1 和 1×4 两矩阵组成，共 8 个新增可训练数。基础矩阵仍存在，这个算例只统计该层新增可训练参数，不能推导整个训练显存一定减半。LoRA 可以用于 SFT，也可以配合适当的其他学习目标。

可验证反馈可用算术答案或程序测试给奖励，流程为输出→检查→反馈→训练更新。检查器可能漏掉边界条件，优化一个分数也可能偏离真正需求。本页只现场检查 17×6 的答案是否为 102，并展示 LoRA 数量关系，不训练语言模型。后训练可能改变格式遵循和任务能力，但不能保证所有事实都正确；应分别检查格式、内容和引用支持。

匿名比较，也要保持实验条件一致

若以后要评价后训练前后变化，应使用同一基座的明确版本，固定问题、检索材料和采样设置，再把回答匿名交给评价者。格式遵循、事实正确、来源支持最好分别评分。某答案列出了整齐的三条建议，但型号错误，格式分可以提高而事实分仍然不合格。分别评分可以避免“看起来像好助手”掩盖具体错误。

课堂答案对只训练我们辨认反馈数据；它们没有经历从参数更新到新输出的过程，因此不能证明哪一种训练算法优于另一种。理解机制与测量效果需要不同证据：流程图说明信号如何进入训练，同条件记录才支持对实际效果的判断。

展开最小公式与数值关系

W′=W+AB；本例 W 为 4×4，A 为 4×r，B 为 r×4，新增可训练参数为 4r+4r=8r，忽略其他层与偏置。SFT 和偏好目标决定学什么；LoRA 决定一部分参数怎样调整。

LESSON 24 / 28

提示、检索、微调与工具

新资料进入上下文，训练改变参数，工具执行明确函数。一个可靠的流程必须追踪来源、单位和停止条件。

先定位需求，再组合机制

“这次用三句话回答”通常用提示；“长期适配固定行为”可以考虑微调；“回答新版手册”通常先更新检索资料；“精确算次数”交给明确计算工具。提示与 RAG 通常改变上下文，微调改变参数，工具负责外部计算或行动。它们能够组合，没有统一赢家。

检索增强生成 RAG 的思路是在回答前找到相关材料，把材料放进上下文再组织答案。本课使用字段与关键词规则检索，没有运行向量嵌入模型，也没有调用真实大语言模型。公开的模板响应只用于检查系统流程，不代表任何产品的语言理解能力。

五条资料，必须保留身份

虚构教学手册，不用于真实设备操作
ID型号 / 版本完整片段
D1AQ-1 / v2 当前正常采样间隔为 10 秒。
D2AQ-1 / v2 当前红灯表示滤芯到期；更换周期为 30 天。
D3AQ-1 / v2 当前仅支持 USB-C 5V 电源。
D4AQ-1 / v1 旧版正常采样间隔为 30 秒。
D5BX-2 / v2 当前正常采样间隔为 60 秒。

查询先按型号过滤，再按版本或预置的当前版字段过滤，最后匹配“采样、指示灯、电源”题型，按文档 ID 升序排序。未指明版本且信息冲突时应澄清，不偷偷选一个版本。检索多少条只是数量，相关性、版本与出处才决定它能支持什么。

从资料到工具：每一步都可验算

题目“最新 AQ-1，5 分钟有几次采样”需要先取 D1 的 10 秒间隔，再把 5 分钟换为 300 秒，形成结构化输入 duration_s=300、interval_s=10。工具校验前者非负、后者大于零，执行 floor(300/10)=30。调用参数与执行结果分栏展示，不能把“打算调用工具”的文本当成工具已运行。

本课约定开始时刻不采样，第一个完整间隔结束后采样一次，因此 95 秒是 9 次。若采用包含起点的另一约定，答案会不同，应先说清计数口径。模板回答引用 D1 说明间隔，再引用工具结果说明次数，数字来源不能混在一起。

给失败一个可定位的出口

一次只注入一个错误。强制取旧版 D4，工具正确算出 10 次，失败最早发生在资料选择；把 5 分钟误传为 5 秒，工具正确返回 0，失败最早发生在单位换算。取消型号过滤会增加 D5 噪声，但 D1 仍排前，本次可能仍答对，不能把风险直接写成已经发生的错误。

缺少来源则停止并请求补充，版本冲突则先澄清，参数非法则显示校验失败，不能无限重试。这是有停止条件的固定工作流。Agent 可以由模型选择下一动作，但画出循环并不自动获得智能。本地规则流程没有真实模型幻觉，也没有外部设备操作；它让我们练习把系统中的错误归因到资料、参数、执行或组织回答。真实 RAG 仍可能忽略证据、引用错误或推断过度，检索正确并不能保证最终回答正确。

把错误归到最早能发现的位置

调试多步系统时，不必先把整段回答删掉重来。先看请求中的条件是否明确，再查检索片段能否支持这些条件；随后检查工具输入是否完整并使用一致单位，再核对执行结果有没有被模板错误转述。最早出现偏差的位置，通常比最终句子中的表面错误更能指导修复。

例如使用旧间隔的结果十次，在算术层面是自洽的；只改模板措辞无法修复它。型号不明确时，追问条件也比随机试用更多文档更合理。实际系统还可记录每一步的输入、结果和停止原因，使复查不依赖猜测。这样的可追溯性来自系统设计，不能仅靠更长的回答保证。

展开最小公式与数值关系

samples(duration_s, interval_s)=floor(duration_s/interval_s)；duration_s≥0 且 interval_s>0。5 分钟×60=300 秒，floor(300/10)=30。开始时刻不采样。
