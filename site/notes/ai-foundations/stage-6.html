LESSON 21 / 28

下一 Token 怎样变成一段回答

给定“设备”，模型怎样接出“正常”，再决定结束？它先计算候选分布，再选择一项；新词进入输入后，才计算下一步。

词表头：把最后的向量变成候选分数

Transformer 输出的仍是向量。词表是模型可选 Token 的清单；词表头是给清单中每一项计算分数的输出层。

本例完整词表只有“正常、异常、〈结束〉”。〈结束〉是表示停止输出的特殊 Token。最后位置的向量为 h=[1,2]。

  1. 打分：h 乘输出矩阵，得到 [1,2,1]。这三个原始分数叫 logits，还不是概率。
  2. 变成分布：用 softmax 得到 [0.212,0.576,0.212]，三项合计为 1。
  3. 解释：当前分布更偏向“异常”，但它不是“设备在现实中异常”的可信度。
两种比例，分配对象不同
位置分配给谁得到什么
注意力中的 softmax可读取的来源位置混合 Value 的比例
词表头中的 softmax词表中的候选 Token选下一个 Token 的概率

这里参数是人工设定值；完整三类头的数值不能当作真实大词表里抽出的前三项。

训练题：把原文与自己错开一格

训练标签就是用来检查预测的正确目标。下一 Token 训练可以从原文直接取得标签，不必为每个位置另写答案。

换到一个独立的四词例子：原文是“〈开始〉 设备 正常 〈结束〉”。这次词表有 4 类，与前面的三类头分开。

输入—目标配对
位置给模型的输入要预测的目标允许读取的输入
1〈开始〉设备〈开始〉
2设备正常〈开始〉、设备
3正常〈结束〉〈开始〉、设备、正常
  • 只错开一次：输入“设备”对应目标“正常”；对应“设备”就变成了复制当前词。
  • 仍需因果遮罩：第二位置不能读第三位置的“正常”，即使整句已在训练数据中。
  • 为何可以并行：训练已有真实前缀，可同时算各位置的题；每道题仍只用允许的信息。

损失：用一个数衡量对正确目标有多没把握

损失是训练要减小的误差指标。本课对正确目标用负对数损失：分给正确目标的概率越低，损失越大。

  1. 前向：由当前参数算出各位置的候选概率。
  2. 评价：读取正确目标的概率，计算平均损失。
  3. 学习：反向传播求梯度，再由优化器更新参数；梯度可影响此前的可训练部件。

生成：选择一个词，再把它接回前缀

前缀是已经给出的 Token，也是本次生成可参考的输入上下文。自回归生成把新选的 Token 加到前缀，再用增长后的前缀预测下一项。

人工有限状态表：完整生成规则
当前前缀正常 / 异常 / 结束的概率下一步
设备[0.6,0.3,0.1]按选词方式取一项
设备 正常 或 设备 异常[0,0,1]选择结束
已选择结束不再计算停止
  • 贪心：直接选概率最大项。本表依次选“正常”，再选“结束”。
  • 采样：按分布随机抽取一项，不一定选最大项；本表也可能第一步就结束。

这张状态表是人工设定，不是训练出的语言模型。它演示了两轮分布不同，以及普通生成时参数保持固定。

训练、逐步生成、重复采样：三种实验别混用

温度是采样前调整分布集中程度的数：本例温度低，最大项获得更高比例。它不判断事实真伪，因此不是准确率旋钮。

各实验固定什么、改变什么
实验已有的信息发生的变化
训练真实输入和正确目标求损失与梯度，更新参数
逐步生成当前前缀，未来词未定选词后前缀增长，重新计算下一步
固定分布抽样 100 次同一前缀、同一分布只重复抽取，观察各项出现次数

固定随机种子，就是让随机数从相同起点产生；相同设置可复现抽样。有限次数的频率仍不必恰等于理论概率。

展开最小公式与数值关系

logits=hW+b；p=softmax(logits)；L=−ln p(正确目标)。多道题取平均：L=(L1+L2+L3)/3。

展开：三词输出头的乘法

h=[1,2]；W 的两行为 [1,0,−1]、[0,1,1]；b=0。输出为 [1×1+2×0, 1×0+2×1, 1×(−1)+2×1]=[1,2,1]。

分布约 [0.212,0.576,0.212]；若目标是“异常”，L≈−ln(0.576)=0.551。形状为 1×2→1×3，一般写作 1×d→1×词表大小。

展开：温度改变了哪些数

pᵢ=exp(zᵢ/T)/Σⱼ exp(zⱼ/T)，T>0；贪心单独选择最大项，不做除以零。

独立固定分布：logits=[ln4,ln2,ln1]
温度概率
1[4/7,2/7,1/7]
0.5[16/21,4/21,1/21]

排序不变，温度 0.5 更集中；若最高项本来错误，集中并不会使它正确。此例与含零概率的人工生成表分别计算。

展开：实现中的两处边界

有些训练库在模型内部完成标签错位；若外部再移一次，会错位两次。这里特殊 Token 和教学分词不代表任一真实分词器的完整方案。

实验中的标量更新使用教学给定梯度 g=0.4、学习率 η=0.1：w 从 1 更新到 0.96。它不是实际 Transformer 反传。

训练不必先随机选词，便可读取正确目标概率来求损失；普通生成也没有每一步现成的标准答案供它训练。

这里的“上下文”指本次可参考的输入内容；第 16 讲的“上下文向量”则是一份由注意力加权读出的数值摘要。

预训练：数据、目标与规模

两套模型参数一样多，为什么表现仍会不同？它们读过什么、练了多少次、怎样选检查点，都影响结果。

预训练：先从大量材料中学习通用的参数起点

预训练是模型面对后续具体任务前进行的基础训练。本课语言模型反复做下一 Token 预测，让参数逐渐学到文本中的规律。

基本动作仍是第 21 讲的前向→损失→反传→更新。规模变大后，还要组织数据批次、保存状态，并用未参与更新的数据检查效果。

先把四个量分开
量含义不能等同于
参数量模型中可学习数值的个数读过多少独立文档
独立数据量去除重复后有多少不同材料材料被重复使用的次数
训练 Token 数训练实际处理过多少 Token独立知识数量
计算预算允许消耗多少计算资源对任务能力的直接评分

同一篇文档出现十次，增加了训练接触次数，却没有凭空变出十篇不同文档。

数据清理：数量之外，还要看组成

下方 12 张人工卡片各有来源、日期、长度和重复组。去重就是按明确规则合并重复材料，而不是只把文本排得整洁。

  1. 先去重：3 张卡属于同一重复组，只保留 1 张；12 张变为 10 张。
  2. 再去损坏文本：排除一张损坏卡。
  3. 再排除测试材料：去掉混入训练集合的一张测试卡，最后剩 8 张。
  • 看比例：去掉某类卡片，会改变语言、领域和年份组成。
  • 看质量：格式干净不等于事实准确；粗糙过滤也可能误删少数表达方式。
  • 防泄漏：测试答案若进入训练，后来测得的成绩就不能充分说明它会处理新题。

这是教学算术：真实开销还受架构、序列长度、硬件与实现影响。这里不提供训练报价或能力预测。

检查点：保存训练走到某一刻的状态

检查点（checkpoint）是训练过程中的存档，包含当时的模型权重；恢复训练还常需优化器等状态。比较不同存档，可以选择后续使用的参数版本。

三类数据的分工
数据什么时候用是否用于当前选择
训练集反传并更新参数用于学习
验证集比较设置或检查点用于选择
最终测试集方案确定后评价不反复用它挑模型

检查点不是带页码的文档目录。参数可能记住部分文本，但生成一句话不保证能准确找回出处。

读曲线：先问它实际测了什么

训练损失在参与学习的数据上计算；验证损失在留出的数据上计算。横轴是训练步数或 Token 数，纵轴才是损失，不能拿播放动画的秒数当训练成本。

教师构造的三种形态：只练习读图
看到什么可以怎样理解
训练与验证损失共同下降对这两份数据的预测改善，仍需检查具体任务
训练 1.8→1.2→0.8；验证 1.9→1.4→1.6后段训练变好，验证变差；调查过拟合或分布差异
损失下降，独立任务分数不变一个指标改善，不保证另一个也改善

过拟合是过度适应训练材料、对新材料效果较差的现象。本页曲线为人工构造，没有对应真实模型成绩。

公平比较前写清五项：任务、数据划分、训练预算、推理设置、评价方法。还应保留失败样本，方便别人复查每个数字的来源。

展开最小公式与数值关系

代币预算：B=P×D≤24。P 是参数单位，D 是训练 Token 单位；两者是独立旋钮。

卡片实验另外按重复组统计独立文档数，把保留卡片的长度相加得到该集合 Token 数。它不直接决定下方独立预算旋钮的值。

展开：真实比较还应保存哪些信息

除了任务和数据，还保存模型结构与参数量、累计训练 Token、随机种子、检查点版本和评估设置。推理时的提示、采样方式不同，也可能改变输出。

计算最优缩放研究在明确条件下研究参数与数据的共同分配；论文关系有适用范围，不能直接当作任意任务的最优配方。

损失曲线评价预测目标；独立任务评价实际需求。二者不能与数据数量、教学预算任意相加，组成一个没有定义的“智能分数”。

LESSON 23 / 28

从续写到按要求回答

模型会续写，不一定会按问题回答。让它看一份好答案，或比较两份答案的优劣，能提供不同的训练信号。

监督微调：把希望模仿的回答作为示范

微调是在已有参数上继续训练，使模型适配后续需求。监督微调（SFT）给出“请求—示范回答”，让模型学习产生这样的输出。

一份人工示范样本
字段内容
请求根据 AQ-1 v2 手册回答采样间隔，并标来源
示范回答正常采样间隔为 10 秒［D1］
  1. 提供上下文：把请求作为本次预测能参考的内容。
  2. 预测示范：逐位置预测示范回答中的 Token，并与正确目标比较。
  3. 继续训练：根据损失求梯度，更新允许训练的参数。

本课常见设置只对助手回答部分计入损失；不是所有 SFT 都采用同样设置。示范是否正确、覆盖是否充分，仍会影响结果。

偏好数据：回答“这两份里更喜欢哪份”

偏好对包含同一问题的两个回答，以及按某项标准选出的较好回答。它提供比较信号，而非一份唯一标准答案。

教师构造比较：问题问 AQ-1 v2
答案内容按正确、相关、有依据的标准
AAQ-1 v2 的间隔为 10 秒［D1］型号正确，来源支持本题
BBX-2 的间隔为 60 秒［D5］自身有出处，却答错型号

本题应选 A。标注记录至少保留问题、被选答案、未选答案和理由；流畅、冗长或有引用，都不能替代对本题内容的核查。

另一对答案若都正确完整，只是长短不同，偏好就可能由“更简洁”的标准决定。偏好依赖评价标准，不自动等于事实真理。

RLHF 与 DPO：怎样把比较用于训练

先补两个词：策略是模型按上下文给候选输出分配概率的规则；奖励是对输出好坏提供的评价反馈。

RLHF 的中文是“基于人类反馈的强化学习”，这里介绍使用奖励模型的代表路径。

参考模型：DPO 训练开始前保留的一份固定模型。用它对回答给出的概率作比较基准；训练更新当前模型，不同步修改这份参考。

两条有代表性的偏好学习路径
方法怎么使用偏好对更新什么
奖励模型式 RLHF先学会给较好回答更高分，再对新回答评分，用反馈改进行动选择语言模型的策略参数
直接偏好优化 DPO用参考模型的概率作基准，直接调整当前模型对两份答案的相对偏好语言模型参数
  • RLHF 的评分器：奖励模型从偏好对学习评分，再评价新回答。之后仍需学习算法求参数更新，评分本身不是梯度。
  • DPO 的学习方向：希望当前模型相对于参考模型更偏向被选回答。通常不用另训显式奖励模型，但仍要训练参数。
  • 不是固定套餐：不必把所有后训练都排成“SFT→RLHF→DPO”。

LoRA：决定哪些参数怎样调整

LoRA是一种参数调整方式：先冻结原来的大矩阵，再训练两个较小矩阵，用它们的乘积形成增量，加到原矩阵上。

四乘四原矩阵有 16 个数。若增量使用 4×1 和 1×4 两个矩阵，只需训练 8 个新增数；原来的 16 个数仍然保留。

目标与调整方式属于不同问题
问题例子
希望从什么信号学习？SFT 的示范答案，或偏好比较
通过哪些参数完成调整？更新原权重，或使用 LoRA 增量

因此 LoRA 可以用于 SFT，也可配合适当的其他训练目标。这个小例子只数一层的新增参数，不能推出整个训练显存一定减半。

可验证反馈：先检查结果，再谈训练

可验证反馈用明确规则检查输出，例如算术答案或程序测试。题目 17×6 的正确值为 102，检查器能直接返回是否通过。

  1. 产生输出：得到待检查的答案。
  2. 检查并反馈：用明确规则给结果评价。
  3. 训练更新：若进入训练流程，再用反馈调整模型；页面只执行检查，不训练语言模型。

检查器也可能覆盖不全。后训练效果应分别看格式是否遵循、内容是否正确、依据是否支持，不能仅看回答是否好听。

聊天时补一句“请简洁”通常只改变当前上下文。没有继续训练和参数更新，就不等于做了一次 SFT。

展开最小公式与数值关系

W′=W+AB。W 是冻结基础矩阵，AB 是学习得到的增量。

设定 rA 和 B 的形状新增可训练参数

一般为 4r+4r=8r。这里 r 是两个小矩阵连接的中间宽度；它限制增量的秩，即能独立调整的方向数量。

展开：怎样验证训练真的改善了回答

使用同一基座的明确版本，固定问题、检索材料和采样设置，再匿名比较输出。格式改善而事实仍错，可以分别记分，不必揉成单一印象。

课堂中的答案对由教师编写，只用于理解反馈；没有实际“参数更新→新输出”的记录，不能用它证明某种算法更好。

奖励是评价信号，梯度是对参数变化方向的计算，优化器再执行更新。三个环节不可画成同一个数。

提示、检索、微调与工具

“最新 AQ-1，5 分钟采样几次？”既要知道新版手册的间隔，又要算对时间。先找资料，再交给明确的计算函数。

四种办法，对应四类需求

上下文是本次计算可参考的输入内容，包括问题、要求和提供的资料。它与模型保存下来的参数不是同一处信息。

先从需求理解名称
需求办法及白话含义通常改变什么
这次用三句话回答提示：在当前输入中写明要求上下文
长期适配某种回答方式微调：用相关数据继续训练参数
回答新版手册内容RAG：先找相关资料，再据此组织回答资料库和上下文
精确计算采样次数工具：调用一个执行明确任务的程序得到外部执行结果

这四种方式可以组合。新手册配固定格式，可以把检索到的资料和格式提示一起提供；无需先把每页手册都训练进参数。

检索：按条件找到能支持答案的片段

检索就是从资料集合中找与问题有关的内容。RAG（检索增强生成）把找到的片段交给生成环节，作为本次回答依据。

虚构教学手册：保留文档、型号与版本
ID身份完整教学片段
D1AQ-1 / v2 当前正常采样间隔为 10 秒。
D2AQ-1 / v2 当前红灯表示滤芯到期；更换周期为 30 天。
D3AQ-1 / v2 当前仅支持 USB-C 5V 电源。
D4AQ-1 / v1 旧版正常采样间隔为 30 秒。
D5BX-2 / v2 当前正常采样间隔为 60 秒。
  1. 筛型号：问题问 AQ-1，先排除 BX-2 的 D5。
  2. 筛版本：“最新”按预置当前版标记判断，排除旧版 D4。
  3. 筛主题：问采样就取 D1；问红灯或供电则对应 D2、D3。

未说明版本而资料有冲突，就先澄清。这里按明确字段和关键词筛选，没有运行理解任意自由文本的语言模型。

工具：先给明确参数，才会有执行结果

工具调用是把结构化输入交给一个程序执行。此处工具只有一个函数：根据总时长和采样间隔，计算完成了多少个间隔。

  1. 取依据：D1 给出间隔 10 秒。
  2. 统一单位：5 分钟×60=300 秒。
  3. 准备参数：duration_s=300 表示时长秒数；interval_s=10 表示间隔秒数。
  4. 校验并执行：时长非负、间隔大于 0，才计算 floor(300/10)=30。

floor表示向下取整，只计完整间隔。本课开始时刻不采样，所以 300 秒是 30 次，95 秒是 9 次。

写出“准备调用计算器”不等于已经运行。实验把调用参数与实际结果分开，让每个数字都能追溯。

组合回答：事实引用资料，数字引用计算

这次回答有两个依据：10 秒来自手册 D1；30 次来自用该间隔执行的计算。不能把工具结果说成手册直接写出的结论。

根据 D1，AQ-1 v2 的正常采样间隔为 10 秒；按本课开始时刻不采样的约定，5 分钟共 30 次。

下方实验按公开模板拼接这句话。字段检索与计算真实执行，资料和模板为教学设定，没有在线语言模型。

真实 RAG 的生成环节仍可能忽略资料或引用错误。看到来源标记后，还要检查它是否支持这句话。

出错时，寻找最早发生偏差的一步

每次只注入一个故障，再从请求往后检查，才能知道应修哪里。

同一问题的故障对照

固定工作流按预先写好的步骤前进；Agent（智能体）系统也可以让模型根据当前情况选择下一动作。这里采用前者，最多执行一次本地工具，失败即停止。

循环次数更多不自动代表更智能。记录每步输入、结果和停止原因，才有助于定位与修复。

展开最小公式与数值关系

samples(duration_s, interval_s)=floor(duration_s/interval_s)；duration_s≥0，interval_s>0。

本课计数从第一个完整间隔结束开始：floor(300/10)=30，floor(95/10)=9。

展开：检索规则与模拟边界

另一类检索可以把问题与资料表示成向量，再做匹配，称为向量检索。本实验没有运行这种算法。

默认精确筛型号，再按指定版本或当前版字段过滤，最后匹配采样、指示灯或电源题型；同等条件按文档 ID 升序排序。

取消型号过滤时，D1 仍可能排第一，因此此次答案可不变。资料不足、版本冲突、非法参数都应有明确出口，不无限重试。

手册全部为虚构教学资料，不用于真实设备操作。规则流程的错误不是实际模型幻觉；它也没有连接真实设备或执行外部写入。
