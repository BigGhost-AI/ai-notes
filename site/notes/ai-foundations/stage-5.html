LESSON 17 / 28

Q、K、V：一次读取怎样计算

当前位置先决定各读多少，再汇总可见位置提供的内容。Q/K 负责匹配，V 提供内容。

先问：查询和内容从哪里来

把“设备／温度／升高”暂定为三个教学 Token，不代表真实分词器一定这样切分。每个位置有一份数字表示。自注意力中，查询 Q、键 K、值 V 都由同一序列的当前表示投影得到；“自”指数据来源相同，并不限制一个位置只能看自己。

交叉注意力则可以让目标序列的当前位置读取源序列：Q 来自 Decoder 当前子层，K/V 来自 Encoder 输出。上一阶段的权重 [0.2,0.5,0.3] 对源向量 [1,0]、[0,2]、[1,1] 加权，得到 [0.5,1.3]。下面换成带投影的新算例，中间数字全部重新开始。

同一份输入，投影成三份工作表示

取输入 X 的三行为 [1,0]、[0,1]、[1,1]。固定 WQ、WK 为单位矩阵，WV 为对角线 [2,1] 的矩阵。因此 Q=K=X，V 变成 [2,0]、[0,1]、[2,1]。例如第三行乘 WV：[1×2+1×0, 1×0+1×1]=[2,1]。

这里让 Q=K 只是为了便于手算，真实训练不要求两套投影相等。Q/K/V 不是模型内藏的三句自然语言，而是完成不同计算的数字。矩阵参数在所有位置共享；普通推理换输入时，中间表示会变，参数不会因此自动更新。省略偏置也是本例的简化。

先算第三行：匹配、分配、汇总

q3=[1,1] 与三个 K 点积，得到 [1,1,2]。点积同时受方向和大小影响，不等同余弦相似度。除以 √2 后分数约为 [0.7071,0.7071,1.4142]；缩放控制数值尺度，接下来的 softmax 才把它们变为非负且合计为 1 的权重 [0.2483,0.2483,0.5035]。

再把三个 Value 分别乘权重，逐分量相加：第一分量是 0.2483×2+0.2483×0+0.5035×2≈1.5035，第二分量是 0+0.2483×1+0.5035×1≈0.7517。结果 [1.5035,0.7517] 仍是表示，不是下一个词，也不是事实正确概率。

整张矩阵：每一行是一位读取者

把三次读取放在一起，权重矩阵 A 有三行三列；行表示谁正在读取，列表示允许读哪里。A23≈0.4011，表示位置 2 读取时分配给位置 3 的 Value 约 40.11% 权重。每行独立归一化，列和没有必须为 1 的要求。A 是 3×3，而输出 Y=AV 是 3×2。

固定 Q/K，只把 v2 从 [0,1] 人工改成 [0,5]，权重不变，y3 的第二分量增至约 1.7448。恢复 V 后，把 q3 改为 [2,0]，权重变成约 [0.4458,0.1084,0.4458]。这是两种局部干预，不能推断改原始 X 只会影响某一条通道。正常改 X 要重算 Q/K/V。一个头的热图也不足以解释整个模型的最终决定。

把“重要”拆成可以检查的问题

试着用加权采购来理解这次读取：一份清单规定从三个来源各取多少，三个来源提供的实际内容另有清单。取货比例没有改变，不代表拿回的东西相同。如果第二个来源换了内容，最终组合就会变；如果改变了需求，分配比例也会变。这一类比只解释配比与内容的分工，模型没有真的在做采购，向量每一维也不一定有可以命名的含义。

读取矩阵时先做三个自检。第一，指着一行说出“谁在读”，再指着一列说出“读谁”；不要被热图颜色吸引而忽略坐标。第二，把该行所有权重加起来，允许四舍五入误差，但内部计算应为一。第三，检查输出维数是否与 Value 相同，而不是与来源个数相同。三来源、二维 Value 的结果是二维，不能因为有三个来源就给输出填三个分量。

最后，用一个反例约束“最重要的词”这种说法：某来源权重大，但它提供的某个分量恰好接近零，对这个输出分量的贡献仍可能很小。后续还会有其他头、输出投影、残差和 MLP。因此我们能够解释本头这一行怎样计算，却不应凭这张局部权重图宣布模型为什么做出了最终判断。

展开最小公式与数值关系

Q=XWQ，K=XWK，V=XWV

A=softmax(QKᵀ/√dₖ)，Y=AV。softmax 沿每一行执行；数值实现先减去该行最大分数，再取指数与归一化。

LESSON 18 / 28

多头、位置与因果遮罩

三种机制解决三件事：不同投影提供多组读取，位置机制提供顺序线索，遮罩限定信息权限。

两个头：分别计算，再拼接

把输入扩成四维 [1,0,1,0]、[0,1,0,1]、[1,1,1,1]，重复分量仅为沿用上一讲数字。头 1 读取前两维，Value 第一分量乘 2。头 2 读取后两维，把 Query 的第二分量取反，Key 与 Value 不变。每个头都有自己的匹配和两维输出。

第三行头 1 输出约 [1.5035,0.7517]；头 2 权重约 [0.5760,0.1400,0.2840]，输出约 [0.8600,0.4240]。拼接得到四维 [1.5035,0.7517,0.8600,0.4240]，再乘四乘四的输出投影 WO。本例默认 WO 为单位矩阵，实际学习时它可以重新组合各头结果。头数不是深度，也不能预先认定某个头必然负责语法或事实。

位置：同一内容出现在不同地方

只看全可见、没有任何其他顺序机制的最小自注意力：交换前两个输入行，输出也会相应交换；跟踪同一个 Token，它的表示没有因为“站位不同”而获得新的线索。加入人工位置表 [0,0]、[0.2,0]、[0,0.2] 后，Token 移动而位置表留在原地，实际参与匹配的输入随之改变。

加法位置表示可用固定函数，也可由训练学习。RoPE 是另一种方式：按位置旋转 Q/K 的分量，使点积携带相对位置关系，它不是把旋转后的向量统一加到词嵌入上。上面的重排结论有明确前提，不能扩张成所有没有显式位置表的因果网络都完全没有顺序信号。

遮罩：先排除，再重新分配

恢复二维基准算例，位置 2 的全可见分数为 [0,0.7071,0.7071]。因果预测时，第三个输入是未来，必须在 softmax 之前排除。剩下两项重新归一化为 [0.3302,0.6698]，第三项为 0，输出约 [0.6605,0.6698]。

把禁用分数写成 0 并不能屏蔽，因为 exp(0)=1；只把 V 清零也不等价，因为其余权重没有重新分配。本课通过直接排除禁止项实现计算。可见表保留主对角线和左下三角：位置 2 可以读取位置 1、2。当前位置输入与需要预测的下一个 Token 不同，因此保留当前位置并不泄漏答案。

做一个可反驳的未来信息实验

固定因果遮罩，改变位置 3 的原输入并重算 Q/K/V，观察位置 2 的输出应不变；关闭遮罩，位置 2 就可能被位置 3 影响。用数值差而不是虚构准确率证明信息隔离。位置 3 自己的输出仍可能变化，这与位置 2 被保护并不冲突。

每次对照只动一个条件。位置向量不负责禁止未来，多头也不会自动纠正泄漏；遮罩限制信息，并不等价于所有位置机制。训练时整句答案可以在内存里，但每道预测题的可见范围仍要符合任务设定。教学逐行展示只帮助阅读，各行的注意力计算并不依赖前一行先算好。

用同一问题排查三个机制

假设输入是一段操作步骤，我们要判断后一个动作是否依赖前一个动作。首先问模型有没有收到位置线索；其次问当前任务允许它读取哪些步骤；最后才看不同头怎样使用这些可见信息。这三个提问顺序不是程序的固定执行顺序，而是帮助我们把问题拆开。只增加头数，不会自动把未来信息从所有头中删掉；只加入位置表示，也不会自动遵守因果预测的训练规则。

在实验中记录基准和修改后的同一行输出，比只盯着变化最显眼的格子更有帮助。比较未来干预时固定查询位置二，改变第三位置；不要同时改查询位置。比较位置机制时固定全可见范围，交换第一、二个 Token 后跟踪同一个 Token，不能误把“第一行变了”直接当作位置机制有效的证据。第一行可能只是换了另一个内容。

展开最小公式与数值关系

MultiHead(X)=Concat(head1,head2)WO

A=softmax(QKᵀ/√dₖ+M)，允许项 M=0，禁止项 M=−∞。本例每个头输出 3×2，拼接为 3×4，WO 为 4×4。

LESSON 19 / 28

打开一个完整 Transformer 块

本课固定使用 Pre-LN：先归一化，再进入子层；两条残差保留各自的原输入。

先固定全图，再看内部运算

HLN1 → 因果多头注意力与 H 相加 → RLN2 → MLP与 R 相加 → Z

注意力负责跨位置读取，MLP 继续加工每个位置已得到的表示。每个接口都是 n×4；注意力内部两头各为 n×2，拼接及输出投影后回到 n×4。相加的两端必须同形状，不能把两个头的拼接误当作残差。

这套结构称为 Pre-LN，归一化在子层之前。它不是所有 Transformer 的唯一结构；原始论文采用另一种 Post-LN 顺序。实验使用推理模式，不加 dropout，所有参数是人工固定值，不是训练好的语言模型。

LayerNorm：在一个位置内部调整尺度

取一行 [1,3,1,3]，均值为 2，减去均值后为 [-1,1,-1,1]，方差为 1，除以标准差后仍近似这一组值。本例 ε=0.00001 用于避免除零，γ=1、β=0；真实训练还可以学习逐维缩放 γ 和平移 β。

把整行改为 [12,16,12,16]，归一化后仍近似 [-1,1,-1,1]，说明整体放大和平移被抵消；单独改一个分量则会改变相对形状。这里每个 Token 单独沿特征维度计算均值和方差，不跨整句话求一个平均值。LayerNorm 仍可输出负数，与生成非负注意力权重的 softmax 不是一回事。

残差与 MLP：保留，再加工

一个独立残差算例：h=[1,0,2,0]，人工子层输出 f=[0.2,-0.1,0,0.3]，相加得 [1.2,-0.1,2,0.3]。把 f 设为零，结果就是 h。直通路径有助于信息和梯度传播，但不是承诺网络永远不改变输入或所有训练难题自动消失。

本实验 MLP 为 4→8→4：先展开特征，经过 ReLU，再压回四维。对每一位置使用同一套参数，MLP 自身不在不同位置之间汇总；它收到的输入却可能已包含注意力读来的其他位置的信息。若仅干预 MLP 的某一行输入，其他行不变；若干预整块输入，影响可以先经注意力传播。许多实际模型使用 GELU 或门控变体，本课以 ReLU 保持运算可追踪。

从当前输入重算，别拼接不兼容的例子

完整块另取 H=[[1,0,2,-1],[0,2,-1,1],[2,-1,1,0]]，每行方差非零。LN1 后再计算两头 Q/K/V，不能把第 18 讲未经归一化的注意力数值贴进这里。面板逐步展示 H、LN1、每头权重、MHA、R、LN2、MLP、Z，数值链在同一次运行中保持一致。

模型可以堆叠多个同类块，一般各块使用不同参数。Pre-LN 堆叠后还通常有模型级最终归一化，再送入下一讲的词表头。训练仍是损失→反向传播求梯度→优化器更新。WQ/WK/WV、WO、MLP 权重以及 γ/β 是参数；这次的 Q、注意力 A 和 Z 是激活。换句输入重新算激活，不能因此说模型重新学习了。

用尺寸检查理解每一条支路

可以把每层输出想成一张有三行、四列的表，三行跟随三个位置，四列是每个位置的特征。当你沿主干往上走，表的宽度保持四；进入多头内部时暂时拆成两个各两列的表，进入 MLP 内部时暂时展开为八列。这些变化都不意味着句子突然增加或减少了 Token。残差的原表和新表相加，也没有把行数或列数翻倍。

如果实现里把三乘四的主干直接与三乘八的 MLP 中间结果相加，就暴露了接口错误：缺少压回四维的第二次线性变换。相反，若维度完全匹配，也只能说明尺寸合理，不能保证信息流和数值正确。还要检查第一处归一化是否送到了注意力支路、原输入是否留在直通支路，以及第二次相加使用的是否是第一次相加结果。尺寸、连接和数值是三种互补的检查。

展开最小公式与数值关系

R=H+MHA(LN1(H))；Z=R+MLP(LN2(R))

LN(h)=γ⊙(h−mean(h))/√(var(h)+ε)+β；方差除以特征数 4。实验 MLP 用 W1=[I,−I]，W2=[0.25I;−0.25I]，偏置为 0；ReLU 后组合恰好得到 0.25 倍输入。这是便于验算的特殊参数，不代表一般 MLP 都是线性的。

LESSON 20 / 28

BERT、GPT、T5：从信息流辨认架构

网络怎样连接，与它被要求预测什么，是两个需要分别回答的问题。

三张地图，先找读取来源

Encoder-only 在给定输入内部做双向读取，适合形成利用左右上下文的表示。Decoder-only 在同一序列里读取已有前缀，使用因果范围继续预测。Encoder–Decoder 有两条序列：源端双向读取，目标端因果读取；目标端还通过独立交叉注意力子层读取完整的源表示。

在翻译时，整段源文已经给定，因此目标端可读完整源文；未来译文尚未确定，不能读。这两件事不矛盾。Encoder 和 Decoder 是信息流组织名称，不是给模型划分“理解脑”和“说话脑”。结构有共同部件，训练目标、数据与适配方法也决定最终能完成的任务。

BERT：藏内容，不是关掉一条连线

将教学输入“设备／温度／升高”中的温度换为 [MASK]，原词温度保留在目标卡。该位置仍可读左边设备和右边升高，利用已给定的上下文恢复被藏的内容。这里“遮词”改变的是输入 Token；因果遮罩改变的是连接可见范围。

这个示意把选中位置全部换成 [MASK]，用于讲清目标；原 BERT 的选中位置并非全部如此替换，不能将玩具规则当作完整预训练配方。恢复词的答案来自原文标签，面板没有调用真实模型预测。BERT 类表示可通过合适任务头与微调适配分类、抽取等任务，不能简单称为“只能分类的模型”。

GPT 式：一条序列内处理前缀

输入“设备／温度”，每个位置通过因果注意力和 MLP 等部件加工，最后一个位置的表示送词表头，预测接下来一个 Token。典型 GPT 式 Decoder-only 没有独立 Encoder，也没有必须从其读取 K/V 的交叉注意力。

原始 Transformer 右半边 Decoder 含有交叉注意力，不能未经修改就当作 GPT 结构图。删掉图上的模块只说明组织差异，不会自动得到训练好的 GPT。本课使用的 Pre-LN 图与原始 Post-LN 图也要分开：前者子层之前归一化，后者先做子层与残差相加再归一化。架构名称不是能力排名，更不是聊天产品的同义词。

T5：源序列和目标序列可以不同长

在 Encoder–Decoder 的交叉注意力中，Q 来自 Decoder 当前子层，K/V 来自 Encoder 输出。如果目标有 3 个位置、源有 5 个位置，权重矩阵就是 3×5，每个目标位置占一行。自注意力则在同一序列内部构造 Q/K/V，不能只把一个矩阵改名就称为 cross-attention。

T5 使用文本到文本的组织，也包含去噪训练：将源文一段内容换成哨兵标记，如“设备 <extra_id_0> 升高”，目标包含标记和缺失的“温度”。这是最小片段恢复示意。它也预测 Token，却仍是 Encoder–Decoder；“预测 Token”不是网络层名，也不是 Decoder-only 的充分定义。面对抽取、翻译、续写任务，先说明输入输出与可见范围，再讨论某类架构为何合适，同时允许有合理适配的其他方案。

同一任务可以有不同适配方案

面对“从手册句子中抽取设备名”，一种方便的方案是让双向编码器为每个输入位置生成表示，再为位置打标签；面对翻译，可以让输出端参考完整源文；面对继续写一段说明，可以直接给因果模型一个前缀。这些是帮助解释信息流的代表方案，不是对其他方案的禁令。因果模型也能把抽取任务写成文字回答，编码器也能配合其他生成组件组成系统。

因此，看到一个新模型介绍时可以先写两行笔记：第一行画结构，标输入序列、输出序列和注意力来源；第二行写训练题目，标哪些内容给定、哪些内容需要预测。只有这两行都说清楚，才继续比较数据规模、训练方法与任务成绩。不要用模型名称或年份替代这两项判断。

展开最小公式与数值关系

源长 n，目标长 m：Encoder self-attention 为 n×n；Decoder self-attention 为 m×m；Decoder→Encoder cross-attention 为 m×n。前两者 Q/K/V 来自各自序列；交叉注意力的 Q 与 K/V 来自不同序列。
