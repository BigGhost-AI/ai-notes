A LITTLE MATH, WHEN YOU NEED IT

随时可以回来的工具箱

四组公式，连接整条主线

神经元：z=w·x+b，a=φ(z)。乘权重、相加、加偏置，再经过激活。回到第 1 讲

损失：回归可用 (预测−目标)²；分类可用 −ln p(正确类别)。把误差变成能优化的数。回到第 4 讲

学习：参数 ← 参数 − 学习率 × 梯度。梯度说局部变化方向，学习率控制走多远。回到第 5 讲

注意力：A=softmax(QKᵀ/√dₖ+M)，Y=AV。逐行匹配，屏蔽禁止位置，再汇总 Value。回到第 17 讲

向量、矩阵、梯度，按需补一点

向量先理解为一排数；矩阵是一张数字表。课程约定每行一条样本、每列一个特征。矩阵乘法的一项，是左边一行与右边一列逐项相乘后相加。

导数回答“输入小变一点，输出大约变多少”；多个参数各有一个变化率，合在一起是梯度。链式法则把沿路径的局部变化率相乘，多条路径的贡献相加。

指数让数变正，softmax 再除以总和；对数将乘法关系变成加法关系。分类损失先抓住“给正确答案的概率越低，惩罚越大”，无需先背完整推导。

容易混淆的十组术语
术语怎样区分
参数 / 激活参数描述计算规则；激活来自这条输入在当前规则下的结果。
架构 / 训练目标架构组织计算；目标规定模型要从数据中学什么。
梯度 / 更新量反传计算梯度；优化器结合学习率与状态决定更新。
训练 / 推理训练改变参数；普通推理用当前参数计算。
batch / step / epoch一批样本 / 一次参数更新 / 一轮遍历训练集。
Token / ID / Embedding切分后的单位 / 词表编号 / 查得的向量表示。
logit / 概率 / 类别任意分数 / 归一化输出 / 按规则选出的离散结果。
LayerNorm / softmax前者调整表示的尺度，后者常把分数归一化为分布。
参数量 / 上下文长度可调数字的数量 / 一次输入能够处理的位置数量。
RAG / 微调 / Agent外部资料进入上下文 / 用数据更新参数 / 组织调用与反馈的系统。
AI 的地图：神经网络是重要主线

人工智能研究让机器完成感知、推理、规划和行动等任务，包含规则与搜索等路线。机器学习通过数据改善系统；深度学习以多层网络学习表示。树模型、搜索和规则系统仍可与网络组合。

监督学习使用外部给定标签；自监督从数据构造目标，例如错开一位的下一词预测；无监督也可以有聚类或重建的优化目标；强化学习从与环境交互得到的回报学习决策。它们是学习信号的区别，不是互斥的应用排行榜。
