A LITTLE MATH, WHEN YOU NEED IT

随时可以回来的工具箱

四组公式，连接整条主线

神经元：z=w·x+b，a=φ(z)。乘权重、相加、加偏置，再经过激活。回到第 1 讲

损失：回归可用 (预测−目标)²；分类可用 −ln p(正确类别)。把误差变成能优化的数。回到第 4 讲

学习：参数 ← 参数 − 学习率 × 梯度。梯度说局部变化方向，学习率控制走多远。回到第 5 讲

注意力：A=softmax(QKᵀ/√dₖ+M)，Y=AV。逐行匹配，屏蔽禁止位置，再汇总 Value。回到第 17 讲

向量、矩阵、梯度，按需补一点
  • 向量：一排有顺序的数。例如 [0.8,0.3] 分别记录一台设备的温度与振动指标。
  • 矩阵：一张数字表。本课程常约定每行一条样本、每列一个特征；换公式时仍要检查轴的含义。
  • 矩阵乘法：选左表一行、右表一列，对应数字相乘再相加，得到结果中的一项。
  • 导数：一个量小变一点，另一个量大约变多少。对多个参数分别计算这种变化率，排在一起就是梯度。
  • 链式法则：沿计算依赖逐步传递变化率；一条路径上的贡献相乘，多条路径的贡献相加。
  • softmax：先对分数取指数，再除以指数总和，得到非负且和为 1 的数值。
  • 分类损失：先掌握 −ln p 的作用：给正确类别的概率 p 越低，惩罚越大。
容易混淆的十组术语
术语怎样区分
参数 / 激活参数描述计算规则；激活来自这条输入在当前规则下的结果。
架构 / 训练目标架构组织计算；目标规定模型要从数据中学什么。
梯度 / 更新量反传计算梯度；优化器结合学习率与状态决定更新。
训练 / 推理训练改变参数；普通推理用当前参数计算。
batch / step / epoch一批样本 / 一次参数更新 / 一轮遍历训练集。
Token / ID / Embedding切分后的单位 / 词表编号 / 查得的向量表示。
logit / 概率 / 类别任意分数 / 归一化输出 / 按规则选出的离散结果。
LayerNorm / softmax前者调整表示的尺度，后者常把分数归一化为分布。
参数量 / 上下文长度可调数字的数量 / 一次输入能够处理的位置数量。

AI 的地图：神经网络是重要主线
  • 人工智能（AI）：让机器完成感知、推理、规划和行动等任务的研究与技术，包含规则、搜索等多种路线。
  • 机器学习：主要通过数据改善系统在任务中的表现。树模型与神经网络都可以用于机器学习。
  • 深度学习：使用多层神经网络学习表示，是本课程主线。

还可以按“学习信号来自哪里”区分训练方式：

  • 监督学习：使用外部给定的已知结果作为标签，例如检修人员标记设备正常或异常。
  • 自监督学习：从数据本身构造目标，例如遮住一个词让模型预测，或预测后续 Token。
  • 无监督学习：没有外部类别标签，也可以用聚类、重建等目标学习数据结构。
  • 强化学习：从与环境交互的回报中学习怎样选择行动。

这些是在比较学习信号；同一系统可以组合多种方法。
