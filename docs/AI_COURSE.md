## 怎样预览和上传

保留整个 `site/` 目录结构。打开 `site/index.html`，或在项目根目录运行：

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory site
```

访问 `http://127.0.0.1:8000/`。按现有流程由你上传/推送至 GitHub。GitHub Pages 仍只部署 `site/`，无需 npm 构建、服务器后端、API 密钥或 CDN。此次没有提交、推送或公开部署。

虽然课程允许多文件，它仍是普通静态 HTML/CSS/JavaScript。离线阅读时要保留 `assets/` 与相对目录；不要只发送一个章节 HTML。外部参考资料链接需要联网。浏览器的本地文件存储限制可能影响进度保存，遇到提示时用导出/复制保留笔记。

## 怎样维护内容

可直接修改最终 HTML；也保留了 `course-source/ai-foundations/` 下的结构化源文件，便于统一维护 28 讲。每个 `stageN.json` 包含正文、公式、实验 HTML、测验、阶段练习和来源；JS/CSS 同目录保存。按当前 `.gitignore`，`course-source/` 仅保留在本地，不会进入普通 Git 提交；完整交付压缩包仍包含源文件，便于备份。

从项目根目录重新生成课程（仅需 Python 标准库）：

```sh
python3 course-source/ai-foundations/make_extras.py
python3 course-source/ai-foundations/build.py
```

生成器只更新课程目录，不覆盖知识库首页或旧文章。改了课程标题/摘要后，应同时修改首页课程卡片。不要混用直接编辑产物与重新生成，否则直接修改会被源文件覆盖。

`train_digits.py` 是可选的研究复现脚本，运行它额外需要 NumPy。发布网页不需要运行训练脚本。修改模型后须同步模型文件、页面记录和样本说明；不能只更改架构而沿用旧权重。

## CNN 的可核查记录

810 参数：8 个 3×3 卷积核及偏置（80），ReLU，2×2 平均池化，72→10 全连接及偏置（730）。使用 UCI 手写数字的 scikit-learn 1797 样本子集；随机种子 20260913，按类划分训练 1074、验证 359、测试 364。训练 60 轮，batch 64，SGD 学习率 0.035、momentum 0.9；按验证损失选第 60 轮。最后测试 351/364 正确（96.43%），损失 0.1110。该划分不等价于对新书写者、照片或任意手绘输入的可靠性保证。

网页包含各类第一条测试样本和三个真实误判；不是只展示成功结果。JS 与 Python 导出的 13 组概率最大差约 8.19×10⁻¹⁶。来源许可与归一化/重划分说明见 `course-source/ai-foundations/DATA_LICENSE.md`；完整训练曲线、划分索引和数据哈希见 `digits-record.json`。

## 正文编辑与阅读层次

28 讲主线与四个选修的说明已按初学者阅读顺序重写。维护时延续以下原则：

- 新概念先说白话含义、给具体例子，再介绍正式名称和符号。第一讲先区分输入、标签、参数与预测。
- 一段只承担一个解释；并列区别用带关键词的要点或对照表，计算过程用有序步骤，不把长句机械拆成列表。
- 关键结论与必要算例直接可见；较长证明、完整参数和补充边界放入 `details`，保留打印可读性。
- `.concept-list` 为成组的术语定义，`.reading-note` 强调容易混淆的关系。第一讲 `.concept-table` 在手机上按条目展示，保留每项来源与用途。
- 改动正文时，同时核对公式区、实验对照和测验解析；不要让同一算例出现两组不一致数字。
